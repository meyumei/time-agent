# T2.3 通用组件库（2026-11-03）

新增 `ui/components` 组件库，统一了页面顶栏、主操作 FAB、分段切换、日期/时间选择、时间范围、时长、重复规则、提醒、任务/项目选择，以及状态反馈、空状态、加载骨架、详情面板和撤销 Snackbar。组件采用受控参数，不直接写数据库；已有页面先接入 `AppTopBar` 和 `PrimaryFab`，编辑器全面迁入留给 T2.5，业务规则仍由各自 Repository/CommandExecutor 负责。
