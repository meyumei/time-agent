# 0.4.0：同页可执行 Agent 与手机交付

本轮按 2026-10-21 最新反馈实现。完整要求见《第五轮同页Agent与UI开发计划》。不制作 HTML。

- 语音结束后留在时间轴。顶部显示原始转写、执行结果和追问；继续长按说话或文字补充，可收起对话。
- 明确可撤销的任务、计划、实际记录直接执行。支持实际记录修改/删除、任务完成/取消、课程单次移动/取消、计时和示例课程整批取消。真正歧义、时间冲突及未来实际记录才确认。
- “记录睡眠一点半到八点八点半”会修正紧邻的同小时口述重复，并按当前时区推断最近已经结束的睡眠；23:30–08:30 跨昨夜到今晨。显式日期优先。
- 可以在同页补充缺失时间、指定同名任务 ID、说“确认”“取消”“把刚才睡眠改成两点到九点”“删除刚才的记录”“撤销这次”。
- 新任务和计划共用一个数据库事务及一次撤销；保存请求有独立 ID，重复提交不重复写入。修改、删除与确认前重验版本和冲突，撤销不会覆盖别人的更新。
- 常用表达离线解析。助手设置中填写 DeepSeek Key 并开启“智能理解”后，未理解的表达自动调用官方接口，附带最近8条对话和有数量限制的对象清单。录音不发送；密钥仍使用本机 Keystore。
- 日布局最多缓存32天，分数滑动复用布局；稳定事件 key 与延迟位置计算减少卡片重建。保留00:00–24:00同屏、双指缩放、点击/拖选添加及冲突标记。
- 按用户指定，实际调用反重力官方 CLI 的 `gemini-3.8-flash-high`，生成主题、导航和时间块视觉代码，整合后由本地编译及界面测试核验。WorkBuddy更新后的 CLI 当前返回 `Authentication required`，DS4.1 Flash 本轮未调用成功；文件交付由本机完成。

最终测试数字、APK签名/原生库校验见 `outputs/v0.4.0/verification.json`；手机端下载路径与两端SHA256见 `outputs/v0.4.0/phone-delivery.json`。最终检查数字见文末。

真机范围：本轮连接了用户指定手机并验证文件传输；手机麦克风准确率、实际DeepSeek自然表达效果和手势帧率仍需在安装后使用验证。自动测试覆盖界面、实际Room写入、回滚、撤销及真实PDF，不替代真机麦克风或帧率测量。官方教务真实账号登录仍未验收。

数据库仍为v2，无破坏性迁移；APK与0.3.1保持同一签名，可覆盖升级保留数据。连接只用于指定手机交付，不改动Termux既有项目和会话。
