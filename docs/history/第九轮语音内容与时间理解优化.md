# 0.5.2 语音内容与时间理解优化

版本：0.5.2 / versionCode 9。安装包单独保存为 `outputs/time-agent-0.5.2-debug.apk`，保留上一版。

## 用户原话与预期

- “昨天上午9点到中午12点进行学习数字信号处理。”：实际记录为设备当地时间昨天 09:00–12:00，活动名称“学习”，备注“数字信号处理”；存在唯一未归档“学习”分类时自动关联。不创建待办任务或计划。
- “昨晚睡眠两点到9点”：实际记录为今天 02:00–09:00，名称“睡眠”。“昨晚十一点到早上九点睡眠”仍为昨天 23:00–今天 09:00。

日期相对于提交时的设备当地日期计算，独立于时间轴当前浏览的周。上述句子支持口语数字、阿拉伯数字及省略“记录”开头的已发生活动描述。

## 具体修改

- 统一日期、时钟、时段继承和内容的源位置提取；支持中文月日、上/下周、明早/明晚以及半小时后等相对提醒。
- “下午三点到五点”解析为 15:00–17:00；明确的凌晨和起止日期优先，不把跨天结束时间强行改成下午。
- 学习/复习/预习的科目进入备注；保留姓名、“到书店”“从零开始”“在家学习”等实际内容，学习资料中的日期不会变成结束日期。
- 记录增加独立名称，时间轴、编辑器、修改预览与重复提交检查同步使用。Room v3→v4 增加空字符串默认名称；旧记录仍按任务或旧备注展示，旧历史快照的撤销/重做兼容缺失名称字段。
- 云端结构协议增加可选 notes，提示词同步说明两条用户原话。未使用用户 Key 调用外部模型。
- 修复候选纠错改变日期/数字、无效首个候选提升后续候选、时间连接词误删活动首字，以及“先预览”直接执行等回归。
- 保留原始疑问和否定信息，叙述性问题不自动创建记录；未来实际记录仍按现有流程明确确认。
