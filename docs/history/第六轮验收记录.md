# 第六轮验收：执行后收起与睡眠宽度

日期：2026-10-21。版本：0.4.1，versionCode 6。对应需求见[第六轮修复记录](第六轮收起状态与实际记录宽度修复.md)。

## 交付行为

- 按住说话时顶部继续显示实时文字；识别进入空闲后，独立语音横幅消失。
- 保存、查询、撤销、取消和“记录已存在”等完成结果自动收起为 48dp 单行，保留摘要、展开及撤销入口。时间轴重新获得页面主要空间，默认仍完整显示 00:00–24:00。
- 需要补充、等待确认或失败时保留展开。展开可查看本次对话；手动收起也只占一行。保存已消费的完成事件，状态恢复不会把新的确认界面或已展开的历史再次收起。
- 无重叠实际记录使用正常当天列宽。睡眠与同一天较晚的课程或计划不再互相挤占；时间接壤也不算重叠。
- 实际记录之间重叠时在整列分栏；实际与安排混合重叠的时间组保留对照区域。安排之间的冲突、缓存复用、缩放及点击命中继续保留。

## 复现与修复

原语音横幅允许空闲但文字非空时显示；旧对话收起视图仍有多行，且没有执行完成后的收起事件。实际记录原先按整天固定放在右侧 18% 区域，与是否同一时段无关。

先补失败用例验证根因，再修改横幅可见条件、单行视图、完成事件及按重叠时间组分配的布局。独立审查发现旧完成事件会在状态恢复时被重新消费；补入两个恢复用例，确认原实现失败后，改为只消费新的完成事件。复核未再发现明确 P1/P2。
