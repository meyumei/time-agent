## 用户反馈对应结果

- **R301 首页长按说话**：底部五个位置中间为圆形麦克风。短按仅提示操作；长按启动、松手识别、上滑取消；离开界面或进入后台取消。首次权限弹窗结束后要求再次按住，不因授权回调启动录音。过早返回的识别结果先保留，松手后才进入助手；取消后抛弃。助手页原“点击说话”入口已移除，右上角键盘保留文字输入。识别文本可自动准备本地预览，但保存仍须明确确认。
- **R302 时间轴添加**：点击空白按当前日期和缩放定位，15 分钟吸附，默认一小时；长按空白后纵向拖选。选择后可新建任务并安排、安排已有任务或创建实际记录。表单带入开始/结束日期时间，支持调整。新任务和计划同事务保存；受控的计划写入失败测试确认任务和历史均回滚。双指缩放不触发创建，短横滑继续连续移动日期。
- **R303 DS UI 重写**：WorkBuddy 指定 `deepseek-v4.1-flash` 实际改写 Theme、AppChrome 与 TimelineAppearance。使用暖纸浅色、午夜深色、统一文字与圆角、中心语音导航、独立事件卡片和日程列表。主流程整合并核对，不以模型自称完成作为测试依据。
- **R304 课程与冲突**：课程采用稳定色组，计划为紫色系，实际记录为绿色独立细栏；全天实际记录不再挤占课程/计划分栏。只将课程与计划的重叠判为排程冲突；红色描边、重叠侧线、工具栏数量和成对清单共同说明。清单显示具体重叠时段、两项完整内容并可点击详情。相邻事件不误报。
- **R305 缩放文字**：按实际宽高、可用行数和文字测量安排内容，完整标题优先；足够空间时显示时间、地点与教师。删除固定四行标题和单行地点限制。极窄块仍保留辅助说明和详情入口；无法在任意微小面积内保证任意长度文字可读。放大后完整长标题的真实文字布局测试已通过。
- **R306 自选主题**：工具栏小按钮选择浅色、深色或跟随系统，并持久保存。编辑、助手、四页面及系统栏图标随当前选择调整；未知旧值安全回退到跟随系统。

## 验证细节与范围

从旧版 UI 出发先运行新增交互测试，确认“底部居中语音、空白添加、手动主题”三项失败，再实现并回归。新布局中列表将类型徽标与标题分开，已有流程测试改为通过完整辅助说明定位同一记录；保留实际点击、保存、重复保护和数据库断言。

文字换行测试使用 Robolectric 原生图形，检查 `TextLayoutResult.hasVisualOverflow`；默认影子字体不能代表中文真实换行，未将其行数作为验收结果。Compose UI 使用 411 × 891 dp，截图由应用和实际弹窗视图原生绘制，不是设计稿。

WorkBuddy 首次改写在写完三个文件后触及 CLI 轮数上限；已检查源码实际落盘，并用后续限定文件的任务修正标题测量，后续调用正常返回。没有读取 WorkBuddy 凭据或将用户 PDF、课程截图、密钥发送给模型。外部模型的内部路由未经独立审计，仅记录指定模型调用和实际修改。

DS 源码复查正常返回，并经只读内部复查补充：修正可点击块打断双指缩放、静止双指误创建，以及读屏语音动作不完整。三项均先用回归复现原实现失败，再修正；读屏保留明确开始、结束、取消和真实文字入口。

本轮仍未使用真实 DeepSeek Key 联通云端，也未完成学校账号登录后的课表实网提取；这些沿用[第二轮验证边界](第二轮验收记录.md)。本轮重点验证 UI 和交互，没有将这些既有边界计为已完成。
