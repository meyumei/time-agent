# 第六轮：执行后恢复时间轴与睡眠宽度

2026-10-21 用户反馈：语音执行结束后顶部输入、对话区域持续占据空间；新建睡眠没有重叠，却显示成窄条。本轮继续交付本地APK，由用户自行传输，不连接手机。

本轮目标：

- 录音及识别期间顶部仍显示实时文字，回到空闲后移除独立语音输入横幅。
- 保存、撤销、查询等已完成结果自动收起为单行状态栏，保留结果、展开和撤销入口；原始转写与对话记录保留在展开视图。
- 等待补充、待确认和失败重试保留展开状态；手动收起也必须真正只占一行。
- 旋转屏幕等状态恢复只恢复现有展开状态，不重复消费旧的完成事件；后续任务完成仍可正常收起。
- 没有重叠的实际记录按正常当天列宽显示，包括睡眠与稍后课程或计划同处一天的情况。
- 仅实际重叠的时间组拆分实际与安排区域；实际记录彼此重叠时在可用整列内分栏。保留全天长记录与课程并排比较，以及课程/计划之间的冲突标记。
- 绘制和点击命中使用同一几何计算，保留连续滑动、双指缩放及缓存复用。

定位：原语音横幅在空闲但文字非空时仍显示；对话没有完成后的自动收起信号，收起视图仍由多行组成。原实际区域按全天固定保留18%宽度，没有按时间是否重叠判断。

验证要求：先复现失败，再验证自动收起、横幅消失、重新展开、确认界面和历史展开状态恢复、正常睡眠宽度、接壤不重叠、真实重叠分栏及平移缩放后的点击。最终全量回归、真实PDF、APK签名与原生库检查结果另行记录。
