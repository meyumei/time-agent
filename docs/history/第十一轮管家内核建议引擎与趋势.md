# 第十一轮：管家内核 v1——建议引擎、睡眠去重与趋势（0.7.0）

日期：2026-10-25。本轮是"时间 Agent → 个人管家"的第一阶段：应用开始**主动**告诉你该注意什么，而不是只被动记录。

## 研究输入

- **REA 逆向报告**（`rea-逆向/00-总汇报.md` 及各专题）：华为建议引擎（suggestion 434 文件独立模块 + 端侧 libStressAdvice）→ 本轮建议引擎独立成包、Coordinator 复用 reminders 范式；Notion 日历 availability（空闲时段排程）→ FREE_SLOT 规则直接复用 core `Scheduling.findFreeSlots`；小米 SummaryDraft→Summary 两段式 → **经评估本轮暂缓建表**（见 R1103 说明）；训记断食四件套（widget/后台推进/常驻通知/阶段计算分离）→ 留给后台调度轮次。
- **Hindsight**（hindsight.life，开源手机记忆应用：每 2 秒截屏 + OCR + 本地 LLM 检索）：可学的是"完整自我数据集 + 对话式回忆"的产品愿景、隐私范围选择（只记录所选应用）、处理窗口约束（充电时才处理）。**不照搬**截屏级 lifelogging（隐私与存储成本高，10 小时约 1GB）；其"用 AI 回忆自己历史"方向对应本应用后续的"自然语言检索自己的记录"。

## 需求

### R1101 睡眠来源去重

真机已确认 GB 与小米运动健康会同时向 Health Connect 写同一晚的睡眠（两者算法不同、时长不一致）。同步引擎规则：

- 同一批同步样本内：两条 SLEEP 重叠 ≥ 30 分钟视为同一晚，保留先处理的一条（按 startAt 排序），另一条计入"去重"。
- 与已入库的睡眠记录重叠 ≥ 30 分钟的新样本跳过（先入库者胜，不churn已有记录）。
- `HealthSyncOutcome` 增加 `deduped` 计数，汇总文案增加"去重 N"。
- 已知限制（记录在案）：去重只在同步批次内决策，来源优先级（如"GB 优先于小米"）留待后续轮次的设置项。

### R1102 建议引擎 v1（规格书 §10 首批落地）

- Room v6 新增 `agent_suggestions`：type、title、detail、dedupKey（唯一索引）、status（PENDING/ACCEPTED/DISMISSED/EXPIRED，状态机对齐规格书）、createdAt、decidedAt。
- `suggestions/` 包：`SuggestionEngine`（纯函数：snapshot + zone + now → 候选列表）+ `SuggestionCoordinator`（复用 ReminderCoordinator 的 observe→reconcile 模式，随应用启动常驻）。
- 三条初始规则：
  1. **OVERDUE_TASK**：TODO 任务截止时间已过 30 分钟 → "任务已截止"，detail 含超时多久。dedupKey `overdue:{taskId}:{dueAt}`。
  2. **FREE_SLOT**：今天 08:00–22:00 内用 core `findFreeSlots` 找 ≥60 分钟空闲，且存在完全未安排的 TODO 任务 → 建议把任务安排进空闲段，每天最多一条。dedupKey `free_slot:{date}:{slotStart}`。
  3. **SLEEP_SHORT**：最近一条健康同步睡眠记录在 24 小时内结束且时长 < 6 小时 → 睡眠不足提示。dedupKey `sleep_short:{recordId}`。
- 写入规则：`recordSuggestions` 单事务——PENDING 超 7 天自动转 EXPIRED；同 dedupKey 已存在（任何状态）不再重复建议（DISMISSED 永不复活）。建议为系统生成，不进撤销历史；"忽略"是低风险动作、不可撤销（记录在案）。
- UI：收件箱顶部新增"助手建议"卡片列表（标题 + 详情 + 忽略按钮）。

### R1103 复盘近 14 天趋势

复盘页新增"近 14 天"柱状区：按自然日汇总实际记录分钟数（从记录实时裁剪计算，当日含进行中）。**暂缓建 daily_summary 两段式表**：当前统计源只有本机记录，实时计算永远一致、无半截数据问题；两段式（小米范式）待统计需要聚合外部数据或重计算成本高时再落地，届时直接按 `daily_summary_draft→daily_summary` 建表。

### R1104 非目标

建议的"采纳"动作流（点击建议直接创建计划/延后任务）、WorkManager 后台调度、sleep 来源偏好设置、合并拆分、备份恢复。
