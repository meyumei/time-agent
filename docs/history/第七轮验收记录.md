# 第七轮验收：任务点提醒、笔记、未安排想法与冲突排版

日期：2026-10-21。版本：0.5.0，versionCode 7。基线版本：0.4.1。对应需求与规划见[第七轮计划](../product/第七轮提醒想法与交互改进计划.md)及[0.5.0 原生功能说明](../releases/0.5.0原生功能说明.md)。

## 交付行为

1. **默认任务点提醒（单时点）**：
   - “安排计划”默认仅设单时点提醒（提醒内容、日期、提醒时间），不设结束时间，不默认补一小时，不强占日历时间块。
   - 显式选择“时段”、时间轴拖选和任务详情“安排时间”仍走时段编辑。
   - 时间轴上以独立圆点标记提醒，不占用时间柱宽、不参与冲突排版；点击可直达提醒详情。
   - 提醒页展示系统通知与精确闹钟能力并可跳转设置；首次成功新建按 Android 13+ 规范请求 `POST_NOTIFICATIONS` 权限。
   - 调度系统闹钟并在开机/重启后自动核对未来有效提醒；到点本地原子去重，父任务失效/删除自动撤销。

2. **记笔记功能**：
   - 课程、任务、计划、实际记录、活动父/子模块均增加“记笔记”入口。
   - 编辑器草稿通过 `rememberSaveable` 保持，退出有未保存提示；保存带版本比对防止并发覆盖。

3. **“未安排”灵感想法**：
   - 任务页顶部“未安排”集中管理灵感想法与任务点提醒；
   - 支持文字与语音录入，不设强制起止时段；随时可单键将想法原子安排为单时点提醒。

4. **撤销与重做（Undo / Redo）**：
   - 时间轴、主顶部栏、活动模板和收件箱均提供“重做”按钮（仅在存在已撤销且可重做操作时点亮）。
   - 新的用户编辑使旧重做分支失效，版本号单调递增；想法转提醒等批量操作支持原子一次撤销/重做。

5. **冲突排版（A+B 方案正式上线）**：
   - 由 Gemini 3.8 Flash 设计并经用户确认的 A+B 方案正式接入：周视图将重叠课程/计划合并为整列/对照栏宽度的汇总卡（方案 A），隐藏细碎重叠条；
   - 点击汇总卡展开底部半屏宽卡列表 Sheet（方案 B），直观查看并点击进入各单项详情；实际记录独立保持比较栏。

6. **双指缩放卡顿排查与优化**：
   - 优化时间轴重绘与文字测量边界，避免缩放平移时的多余计算，保留 00:00–24:00 完整全天视图与连续日期体验。
