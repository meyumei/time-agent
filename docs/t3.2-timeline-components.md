# T3.2 时间轴组件化与 1/3/7 视图

本任务把时间轴工具行的日数选择和来源过滤提取为可复用 Compose 组件，并把视口日数真正接到时间轴渲染路径：

- `TimelineDayCountSwitch` 提供 1 日、3 日、7 日切换，保存视口中心和纵向时间锚点。
- `TimelineFilterButton` 提供计划、实际、课表、健康来源的多选过滤。
- 全天计划显示在时间轴日期头下方的独立行，普通时段不再重复绘制全天块。
- 时间轴网格宽度、缓存窗口和双指缩放均使用当前 `dayCount`，不再固定按 7 日计算。
- 既有列表模式、冲突、撤销/重做、提醒点和点按空白创建入口保留。

健康来源沿用现有 `TimeRecordEntity.source == "HEALTH_SYNC"` 标记；没有新增数据库字段或迁移。
