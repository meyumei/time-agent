## 协作边界

DS 按模块领取明确文件范围、次数和停止条件。共享入口、数据库实体与迁移、最终集成由主代理控制；源码候选与合成数据可交 DS，用户的私人数据库、聊天、平台凭据和 Key 不交 DS。主代理独立检查实际 diff、构建退出码、设备原始输出及更新后的数据一致性。

CLI 请求 `deepseek-v4.1-flash`、`effort=max`；每次记录实际返回模型。服务端不返回实际 effort 时记为未知，不宣称已确认最高推理档。
