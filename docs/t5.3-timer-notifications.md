# T5.3 常驻计时通知

2026-11-04。开发记录，未作验收通过声明。

自由计时、专注、训练共用TimerForegroundService和一条常驻通知。服务使用specialUse：用户主动开始的计时需要持续运行，shortService有时限，不适合长会话。

通知包含名称、开始时刻、系统chronometer、项目色，提供停止、切换和可用时暂停/继续。操作带固定requestId及所见版本；停止后结束服务。训练休息/Tabata和专注阶段提示仍保留为低频提示，不新增第二条常驻计时。

默认关闭无计时快捷通知，可在设置开启最近计时、语音、新建任务。锁屏隐藏名称可设置。通知关闭或被划掉不停止计时，返回前台恢复通知并提示一次。

影响L02/L07/L11/L21。无新增数据库版本。恢复验收时检查API33权限关闭、API34划掉、锁屏按钮、服务停止、重复点按和三种主计时之间切换。
