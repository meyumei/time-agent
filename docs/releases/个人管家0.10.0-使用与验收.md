# 个人管家 0.10.0 · 使用与验收

日期：2026-10-27。包名 `com.timeagent`，版本 `0.10.0 / code16`，主数据库 v8，独立训练数据库 v1。保留训练素材和原生 3D 容器修复；0.8.1 原包与本轮第一批 0.9.0 包留存。本项目非 Git，原始源码备份位于 `evidence/butler-upgrade-20261026/baseline`。

本版按用户选择先交付完整 APK，保留数据覆盖安装与真机回归待测。下述桌面自动化不代表实际手机、麦克风、通知权限或真实健康源已通过。

## 六项功能

| 功能 | 入口与行为 |
| --- | --- |
| 可执行建议 | 任务 → 未安排 → 助手建议。安排、换时段、延后截止、开始计时、稍后提醒、忽略；保存前复查真实任务、时长、冲突与记忆规则，支持撤销。 |
| 今日简报 | 时间轴顶部，默认收起。展示下一项、重点与逾期、可用空档、最近睡眠和训练，支持原事项跳转。 |
| 完整备份恢复 | 我的 → 完整本地备份 / 恢复。系统文件选择器导出和选择文件，先校验预览，再勾选确认替换。 |
| 个人记忆 | 我的 → 个人记忆。新增、编辑、确认候选、停用、删除、撤销和 JSON 导出；保留类型、来源与有效日期。 |
| 历史问答 | 我的 → 历史问答，或助手中提问。查询真实实际记录、已完成训练与笔记，显示统计范围和原记录入口。 |
| 聊天文字事项提取 | 分享纯文字到时间 Agent，或我的 → 聊天文字提取。预览、逐条修正、明确确认属于自己后保存，支持整批撤销。 |

## 建议与简报的口径

建议不从卡片文字反推写入动作。卡片持有任务 ID、版本、候选时段和有效日期；执行时重新检查，过期或已变更的对象不能写入。安排必须容纳完整预计时长，开启计时不会自动覆盖已有计时。已执行或撤销的批次不重复执行。

简报的睡眠按起床日汇总：同来源分段取并集，多个来源择一展示并保留来源说明，午睡单列。主睡眠与午睡目前使用时间启发式，不能等同医疗判定；未来未结束片段不作为已完成睡眠。来源读取状态与最新数据日期分别展示，新的运动记录不会把旧睡眠标为今天。数据缺失表达为未查到记录。

## 个人记忆

可说“记住我每周三不练腿”，或手动录入偏好、可核对事实、当前约定。明确指令可直接保存；“从最近实际记录提出候选”只产生未确认候选，不能自动成为习惯。未预置任何演示偏好。

普通文字记忆供查看与核对，不自动理解为复杂排程条件。当前支持两种结构化规则：指定星期避让匹配任务关键词、匹配任务只在每日指定时段排程。每日时段可跨午夜；关键词留空适用于全部任务。规则只在已确认、启用、未删除及有效期交集内参与检查，停用后不再限制新排程。保存计划时再次检查，原有计划不会被静默改写。

## 历史查询与本地处理

例：“上周数字信号处理学了多久”“上次健身是什么时候”“昨天找笔记通信实验”。也可直接设置日期、关键词、任务或活动。相对日期以提问当天为准，周从周一开始；无日期查询全部本地历史。

计时记录裁剪到查询日期和当前时刻，进行中计时截止当前时刻。累计时长逐条相加，去重覆盖取区间并集。训练只统计已完成、已结束的独立训练，按开始日期归属、扣除暂停；与时间轴实际记录分别列示，不相加。笔记仅作为线索，不折算时长。匹配项参与全部统计，页面每类显示前 50 条。未查到记录不等于当天没有活动。

历史答案和明确记忆对话标为仅本地，不会进入后续云端对话的最近上下文；笔记全文和记忆表也不加入云端结构化上下文。语法未覆盖的历史问题可使用筛选页面。云端智能理解仍沿用既有单独开关与 Key 设置。

## 聊天事项的确认边界

每次最多 20,000 字、30 条候选，超长文字提示删减，不截断后自动保存。只处理用户主动分享或粘贴的文字。原句保留在预览及保存后的想法内容、任务说明或提醒笔记中。

问句、否定和引用指令保守忽略；他人发言或邀请提示重新确认。候选默认全部未选中，必须明确确认为自己的事项。无日期进入想法收件箱；只有日期成为任务、截止取当天结束；明确单一时刻成为提醒、不编造结束时间；明确时间范围或时长才成为计划。可在保存前编辑类型、标题和日期。

原文变化、跨日、预览不匹配会要求重新提取。保存为单一事务，后续事项冲突或规则失败会回滚本批所有写入；稳定标记防止重复导入与撤销后重放，也不会覆盖已手改对象。计划冲突需修改后重新保存。

## 备份包含什么

主库所有用户表、取消及历史状态、标签关联、完整操作历史、版本与防重标记、健康同步保护、建议处理状态和个人记忆；独立训练记录与模板、自定义动作、允许的外观和训练等个人设置。导出直接读取全表，不受界面快照的 80 条历史、200 条健康来源或 50 张建议上限影响。动作媒体与 3D 模型随完整 APK 提供。

单个备份上限 32 MiB，超过上限会提示且不生成不完整备份。备份不包含 API Key、云端同意、Keystore 文件、GB 文档 URI 和设备权限。文件含个人记录，应妥善保存。支持本版 v8 和本轮第一批 v7 备份；v7 恢复时记忆表为空，不生成假数据；未知版本拒绝。

恢复会替换两套数据库和允许的个人设置，不合并。校验 SHA256、格式、表与字段、类型、数据关联和训练载荷后，先持久保存当前数据的内部回退副本，再逐库替换；失败会回退，进程中断时下次启动先恢复。若回退仍失败，阻止继续写入并提供重试，保留回退文件。合法删除原记录后等待撤销的未关联笔记完整保留。

成功后重新登记提醒与训练状态，返回时重开主界面。需重选 GB 文件并核对 Health Connect、通知和精确闹钟授权；换手机需重新填写 Key。测试只使用合成数据库，不曾用真实用户库做替换演练。
