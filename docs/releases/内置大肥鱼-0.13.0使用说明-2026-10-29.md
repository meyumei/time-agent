# 时间 Agent 0.13.0 技术体验版

本版继续使用同一条内置大肥鱼，无需另装 DSHA。形象、口吻和动画仍为占位，等待你的素材。实际构建、安装与测试状态见本版验收报告，不能以本说明代替真机验收。

## 从哪里开始

先进入底栏“管家”，使用已有模型设置，点击“准备并启动”。首次准备时保留在 App 中等待进度完成；后续可从相同位置查看运行状态和停止。

底栏中央按住说话，松开识别；上滑取消，文字入口可直接打字。今天、计划、复盘中的中央输入和管家页使用同一会话，文字草稿也共用。未启动或消息过长时原文保留，提示处理后再发送。

| 想做的事 | 入口与返回 |
|---|---|
| 推进项目、安排任务 | 计划 → 项目 → 项目详情 → 下一步 / 安排下一步 → 保存或取消后回到原项目 |
| 补记实际投入 | 今天 → 补记时间 → 保存或取消后回今天；实际记录与计划分开 |
| 只调整这一次习惯 | 今天 → 本次习惯，或计划 → 周期习惯 → 仅本次改期；规则编辑仍是独立入口 |
| 处理期限 | 今天 → 处理期限，或计划 → 生活期限 → 处理 / 仅本次延期 → 返回原入口 |
| 整理临时想法 | 计划 → 收集想法 / 收件箱 → 安排提醒；编辑结束仍回收件箱 |
| 开始训练 | 今天 → 训练，或计划 → 开始训练；继续使用已有动作库、训练记录和 3D 肌群 |

设置、备份、历史等子页面逐级返回。例如管家 → 设置 → 业务备份，返回后先到设置，再回管家。

## 共同记忆与主动话题

管家 → 共同记忆可查交流经历，并打开最近 B站见闻的公开来源。日程、任务、实际投入仍以今天、计划和原业务记录为准。

管家 → 主动话题可保存总开关、聊天开关、活动时段和间隔。时间使用手机本地时区；时段可跨午夜，起止相同表示全天。总开关关闭或在时段外，调度器不再自动唤醒、浏览、写日记或自省。主动话题排在当前用户回复之后，不插入正在进行的用户回合。

“让它先聊一句”是手动发起的话题，返回管家查看回复。设置生效不等于手机已经完成长时间后台验证。

## B站见闻

管家 → 平台连接 → “看看公开内容，和我聊聊”会尝试读取公开标题等资料，保存真实来源，再交给同一会话分享。读取可能需要一两分钟；失败时保留实际错误或已经取得的来源，不编造读到的内容。

收到分享后，可以追问“为什么想分享”“刚才那条的来源是什么”。目前不会把读取标题等资料说成看过视频画面；字幕、评论等能力是否可用以实际工具结果为准。

自动浏览单独开启，默认关闭。公开发布、评论、点赞、关注和私信没有随浏览开关启用。登录二维码需由你在 B站确认，本版不替你确认登录。

## 数据与当前边界

采用同签名覆盖安装，保留已有会话、记忆、业务数据和模型设置。鱼的会话与共同记忆仍在独立运行目录，尚未包含在现有业务备份文件中，请勿把业务备份当成鱼的完整备份。

真人语音、真实平台登录、长时间后台表现以验收报告的实际覆盖范围为准。QQ、抖音、小黑盒和最终角色素材未计入本技术体验版。桌面 Widget 不在本轮范围。
