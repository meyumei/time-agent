## 已落地的代码与界面

- 底部为今天、计划、中央语音/文字、复盘、管家。原有中央按住说话、识别和取消流程保留；生产环境输入接入同一个 FishSession。
- 计划页归集项目、任务、周期事项、生活期限、周目标、想法与附件。项目可打开实际项目详情并继续处理任务。周期页区分本次实例与以后规则，期限页按今天/逾期、7 天内、以后和已处理分组；改期以实际到期日为准。
- 管家原生对话、共同记忆、运行进度、模型设置及 B站连接页已接入。最终角色口吻、称呼、形象与动画保持占位，等待用户素材。
- `:agent-runtime` 在应用私有目录准备 arm64 Linux/proot、Node、Python 和固定版本 DSH；首次启动验证资源散列并显示准备进度。无需安装独立 DSHA。前台服务管理运行及停止；没有承诺 Android 系统长期保活效果。
- 原生输入经自有 JSON 行桥接到官方 SDK，SDK 使用真实 DSH 会话。日程工具回调 Android 的现有 Repository/Planner/Writer，同一模型轮次可以等待真实工具结果。
- 会话 ID 和 DSH 事件历史持久化，重新启动恢复同一会话；不把推理或内部工具事件显示成聊天。共同记忆使用选定 dsh-remembers 的实际 Python/SQLite 服务。
- 现有记想法、提醒、计时、修改、确认、撤销等本地路径作为同一角色的工具；周期任务完成会更新对应实例，不自动生成实际投入。
- B站仅复用所选项目的 CLI 工具，不加载它的另一套角色/宿主/调度器；见闻进入同一个记忆和会话。原生扫码入口已实现，但未完成实际登录验证。内容范围为简介、可用字幕和评论，不声明理解了视频画面。
- 现有业务 Room 版本仍为 11，没有本轮业务数据库结构迁移。

## 安装与首次接线

目标为支持 `arm64-v8a` 的 Android 手机。APK 包含原训练离线资源和新增运行资源，文件较大；首次准备还会解压私有运行环境。五份运行归档展开内容约 808 MB，实际占用还包括目录、会话与记忆，需要额外可用存储。

安装后进入管家 → 模型设置，在手机本地填写用户自己的模型密钥，再点准备并启动。准备完成后从中央输入或管家对话发出消息。设置变更后再次启动使用新设置。常驻通知可返回应用，管家页可停止运行。

正式真机验收至少应记录：一次实际模型回答、同轮真实日程工具调用与返回、退出/再进后会话续接、停止与重启、共同记忆读取、B站真实来源及分享、后台持续运行。当前没有连接的 ADB 设备，未进行本轮安装和上述真机验收；不要求在聊天中提供密钥。
