# 0.5.0 原生功能说明

日期：2026-10-21。本文件描述本轮实际实现的用户可见行为；版本号与 APK 由主代理发布时生成。

## 任务点提醒

- “安排计划”默认打开单时点提醒编辑：只有提醒内容、日期和一个提醒时间，没有结束时间，不自动补一小时，也不写入日历时间块。
- 需要占用日历时间时，在编辑器里显式选择“时段”；时间轴拖选和任务详情的“安排时间”仍直接进入时段编辑。
- 任务页顶部“未安排”入口集中管理想法和任务点提醒：可新增/编辑/归档想法，把想法安排为提醒，编辑/关闭/删除提醒。
- 时间轴上以独立小圆点标出提醒时间，不占时段、不参与冲突；点击打开提醒详情。
- 提醒页展示系统通知与精确闹钟的真实能力，可跳转系统设置；首次新建提醒时按 Android 13+ 规则请求通知权限，拒绝会显示“已保存，通知未开启”。

## 提醒可靠性

- 应用启动时启动唯一的提醒协调器，保存、改时、关闭、删除和父任务完成/取消都会同步系统闹钟。
- 到点投递使用本地数据库原子去重；同一提醒同一时间不会重复通知，父任务完成/取消/删除不投递。
- 正常投递后刷新不会撤掉状态栏通知；只有删除、关闭、改时或父任务失效才撤下。
- 重启/应用更新/时间变化后恢复未来提醒；不补发关机期间错过的时间点。
- 点击通知冷启动或前台都能打开对应提醒详情。

## 笔记

- 任务详情、时间块（计划/实际记录/课程实例）详情、活动父/子模块都有“记笔记”。
- 笔记草稿用 `rememberSaveable` 保留；返回时若未保存会询问“放弃未保存的笔记？”，不会静默丢失。
- 再次打开读取已有笔记；保存带版本校验，不覆盖其他窗口的新修改。

## 撤销与重做

- 时间轴、任务/复盘/我的顶部栏、活动模板和收件箱都有“重做”，仅当存在已撤销且可重做的操作时启用。
- 新编辑（包括课表导入）废弃旧重做分支；版本单调递增。
- 想法安排为提醒是一个原子操作，一次撤销同时恢复想法状态并移除提醒，一次重做同时恢复。

## 冲突排版

- 周视图把连通重叠的课程/计划合并为一个正常列宽摘要，隐藏组内原个体细条；实际记录保持自己的比较栏，不入组。
- 点击摘要打开宽卡 sheet，点课程/计划进入原来的详情；接壤的半开区间不算冲突。
- 设置保留“冲突排版示例”只读入口，正式时间轴已按用户批准的 A+B 方案接入。

## 说明边界

- `deliveredAt` 只表示已向 Android 提交通知，不代表用户已读。
- 声音、锁屏显示、勿扰、省电和厂商后台策略由系统决定；本轮未连接手机实测。
- 精确闹钟不可用时自动使用系统允许的延后方式，界面会明确说明。
