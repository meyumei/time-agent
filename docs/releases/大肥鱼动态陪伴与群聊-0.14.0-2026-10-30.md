# 大肥鱼动态陪伴与群聊 · 0.14.0-preview

日期：2026-10-30。包名 `com.timeagent`，versionCode `24`。

本轮在原生 Compose 界面内加入大肥鱼陪伴、两版实际动作素材、心情与作息、原对话表情，以及默认关闭的 OneBot QQ 群连接。没有新增第二个聊天宿主或记忆数据库。交付 APK 为 `outputs/time-agent-0.14.0-companion-debug.apk`；最终哈希、构建结果和验收范围以 `evidence/fish-companion-20261029/acceptance.json` 为准。

## 已接入的使用路径

- 今天、计划、复盘、管家四个主页与中央语音输入保留。角色显示在应用内容区，可直接拖动；点击在当前界面展开原对话，长按进入陪伴设置。设置页也可从原聊天顶部进入。
- Q版与御姐版共用同一个 `FishSession`、DSH 宿主、人格及共同记忆。设置保存外观、可见性、归一化位置和作息；切换外观只更换角色图集与群聊贴纸。
- 动作随真实发送、工具调用、回复、失败和取消事件变化。闲置时眨眼；思考、读写、挥手、犯困、睡觉、关心和歉意各有对应绘制帧。点击角色不会把正在执行的事务改成空闲。
- 心情使用四个小状态，由输入和回复文本及失败事件驱动；负面含义先于“成功”等正面词匹配，中性回复保留已有心情，闲置半小时后回落。它是轻量表现逻辑，不是情绪识别服务。
- 作息使用仓库实际时区和可配置的起床、睡觉小时，支持跨午夜；消息会唤醒角色，进行中的事务不被时钟覆盖。主动话题继续使用原有开关、时段和间隔配置，首次启动从当前时间开始等待间隔。
- 原聊天面板和管家对话都能呈现六种鱼表情；表情选择器仍通过原会话发送。模型可用 `[[fish:happy]]` 等标记选择同套素材，界面隐藏标记并展示图片。

## QQ 群聊

入口为管家原有的“平台连接”，在 B站设置下方配置已有的 NapCat / OneBot HTTP 服务。没有搭建或登录用户的 QQ，也没有发送测试消息。

- 新配置的接收开关、允许回复开关均关闭，群号列表为空。只有保存了启用和允许回复，并指定群号后，才会调用生成与发送。
- “检查连接”实际读取 `get_login_info`；保存或读取设置也核验连接，在线状态来自接口结果。
- 每15秒读取指定群最近消息；首次读取只装入上下文，不补答旧消息。各群保留最近30分钟、至多30条短上下文，带成员昵称和QQ标识。
- 默认在被@或回复鱼的消息时接话；智能模式另识别“大肥鱼/鱼鱼”加明确问题或请求。普通聊天、自消息、静默时段及频率限制会跳过。
- 默认最短30秒间隔、每小时最多6条、8–23点。支持跨午夜时段，发送成功后才累计次数。
- 回复通过同一个 DSH 实例中的 `timeagent-qq-group-<群号>` 会话生成；群会话沿用共同人格和同一个记忆服务，同时使用现有群范围，避免混入主要用户私聊业务。群会话不能调用私人时间业务工具。
- 发送为真实 OneBot 文本段与图片段，图片取自本轮两版生成素材。关闭回复、移除群或切换端点/Token 后，原连接正在生成的回答不再继续发送。
- 切换连接会清空旧账号的本地上下文与去重状态，重新核验账号并装入历史。单群失败不阻断其他群，空回复、失败或取消都有状态退场。

这是 HTTP 轮询适配，不是 OneBot 反向 WebSocket 服务。需要现有端点支持 `get_login_info`、`get_group_msg_history` 与 `send_group_msg`。真实端点兼容性与QQ登录尚未验收。B站原有链路保留，本轮没有重新扫码、发动态或评论。
