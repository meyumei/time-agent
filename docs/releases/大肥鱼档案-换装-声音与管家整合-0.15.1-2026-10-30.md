# 大肥鱼档案、换装、声音与管家整合

日期：2026-10-30。交付版：`0.15.1-preview / code27`。

本版已完成源码集成、定向检查、构建及安装包资源核对。手机断开后继续完成本地开发；本版尚未安装到手机，也没有本版声音播放、键盘、动画和 B站 HTTPS 的真机通过结论。

## 入口与行为

- 今天：原来的对话预览与今日简报合成一个紧凑管家入口，显示下一项真实安排和最近一句管家回复。点击进入既有「管家」页，继续同一会话；补记时间、本次习惯、处理期限、训练入口保留。
- 管家：保留小标题、原会话、简报和输入栏。运行、形象、平台等大块设置收进右上角「大肥鱼的一切」。简报在会话列表中展开查看详情。
- 键盘：输入栏保持在底部，键盘出现时缩小消息区；不再按键盘状态移除、重建顶部设置区。只在原来位于末尾时跟随新回复，阅读历史时保留位置。实际键盘体验待本版真机检查。
- 大肥鱼的一切：个人档案、换装、表情动作、声音、陪伴与作息、共同记忆、平台连接、主动话题、运行设置、应用设置各有独立入口。
- 平台连接：先选 B站或 QQ群聊；QQ 未填地址时显示尚未配置。B站保留上次操作错误和读取状态，刷新本机登录信息不会冒充在线登录核验。

## 档案、换装和动作

个人档案可编辑姓名、介绍背景、性格口吻、关系场景、问候语和说话示例。支持 Character Card V2 JSON 导入、导出；编辑后保留卡中未知字段。未保存过档案时不覆盖旧人格；保存后只更新既有角色约定中的独立档案块，保留此前文本、共同记忆、身份和会话。QQ 智能接话同时识别用户自定义名字及既有别名。

换装支持原 Q版、御姐版、红色工作服和自行导入的图片。动作支持名称、触发状态、帧间隔、多张有序图片，以及系统原生支持的 GIF / WebP 动画。导入的图片复制到应用私有目录；移除只清理不再被引用的应用副本，不删除用户选择的原文件。部分图片导入失败时回收本次已复制的文件。

当前 GIF / WebP 动画播放使用 Android 9/API28 起的原生解码；Android 8/API26–27 显示静态首帧，可以使用多张有序图片播放动作。内置 Linux / Edge 语音依赖针对 arm64，未验证其他 CPU 架构上的内置运行时；手机系统语音仍取决于设备是否装有中文引擎。

补充素材中，指向、玫瑰、惊讶、睡前四张作为可添加的动作参考；其余图片保留为设计参考。原始图片未覆盖。红色工作服是依据用户三视图生成的单张透明衍生图，现有轻微呼吸效果，**不是整套新工作服动作图集**。来源和散列见 `design/fish-companion/refresh-20261030/asset-manifest.json`。

原图集改为同一画布内的前后帧混合，避免两个半透明图层叠加造成中间帧发白。自定义序列在后台一次载入并缩放，按经过时间选帧，避免逐帧在主线程反复解码。最终视觉连续性仍需手机视频验收，不能从界面文字层级推断。

## 让大肥鱼说话

参考原 qqbot 的 `edge_tts.Communicate`，使用未修改的 Edge TTS 7.3.1 及其依赖；生成 MP3 后由 Android MediaPlayer 播放。没有加入 QQ 专用的 FFmpeg / SILK 转码。

入口：大肥鱼的一切 → 声音。可选晓伊、晓晓、云希，调整语速与音高，试听、停止；可开启仅前台新回复自动朗读。也可切换手机系统语音引擎。每条管家回复有「朗读」入口；失败和完成提示保留可见，切到后台停止播放。

在线朗读会把要读的文字交给 Edge 语音服务。当前提供合成声音，**未克隆原角色声线，也没有依据单张人物图声称获得原声**。上游许可、依赖版本和 SHA-256 见 `vendor/edge-tts/` 与 `THIRD_PARTY_NOTICES.md`。

## B站证书问题

旧版手机实测：内置 Python 的默认信任库有 0 个根证书，访问官方二维码接口出现 `CERTIFICATE_VERIFY_FAILED`。证据为 `evidence/fish-refresh-20261030/tls-before.json`。

本版打包 curl 提供的 Mozilla CA 证书包，并给内置 Python、requests 和 Node 指定证书路径。HTTPS 校验保持开启。主机使用同一证书包实测得到 118 个可信根，官方二维码接口返回 code 0；这证明证书包和调用可用，**不能替代内置 Linux 运行时在手机上的复测**。未扫描二维码或登录账号。
