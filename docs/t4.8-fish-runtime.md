# T4.8 鱼与运行时开发

2026-11-04。用户要求停止测试，当前仅记录开发结果，不作验收通过声明。

## 实现

FishSession 组合运行时控制器、stdio 客户端、聊天显示缓存与待发队列、工具桥、共同记忆网关、平台控制、声音控制与角色状态。仍只有一个 AgentRuntime 与 DSH 会话，原角色、贴纸、QQ、B站、主动关心、Edge/系统朗读、悬浮窗接口保留。

运行时具有 NotInstalled、Installing、Stopped、Starting、Ready、Busy、Stopping、Failed、NeedsKey、UnsupportedDevice。状态页接入需要时自动启动开关、失败三次停止重启、手动重试、原因和本地状态日志。Key 仍从既有加密设置读取；非 arm64 保留本地业务。协议声明来自当前 host.mjs 的 ready 帧，没有假设额外远端握手。

聊天发送先解析本地指令；本地会话结果在原聊天显示“本地执行”，确认预览和撤销仍走统一命令入口。`@鱼` 显式绕过本地解析。无运行时的普通消息保留在待发队列；本地结果作为上下文在下一次鱼消息前交给 host，不再执行一次业务命令。

共同记忆权威仍在 dsh-remembers。补充 host 的 memory_edit/memory_delete 与服务端对应路由，按所见原文校验后修改同一条权威记忆，更新倒排索引；读取/搜索继续原接口。运行时停止时显示内存只读缓存。当前记忆删除沿用服务端 forget，不包含本地业务撤销历史。

## 协作

真实 WorkBuddy CLI 的 deepseek-v4.1-flash；请求 effort=max，实际 effort 未返回。DS 负责限定 fish 文件，主代理接设置页面、本地路由、共享 ViewModel 和插件协议，独立核对现有 host 动作与 rootfs 标记。CLI 请求 max-turns=85，结果 num_turns=384，未按请求轮数停止，记录该限制偏差。未授予设备、命令或私人数据读取权限。
