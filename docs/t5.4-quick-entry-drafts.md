# T5.4 快捷记录持久草稿

2026-11-05。本批只做源码、必要 Kotlin 编译和有界只读审查，所有测试及手机操作继续暂停。

## 改动

快捷记录编辑器原来只用 remember 保存弹窗字段，新建状态与编辑对象也未落盘。本批新增应用私有偏好草稿：保存原实体、原内容版本、固定的新记录编号、初始字段、当前字段、原始时长文本和提交请求编号。每次字段改变立即保存这个小型草稿；列表提供逐项恢复入口。记住弹窗编号只负责界面恢复，真正的输入来自持久存储。

关闭改用共享“保留草稿 / 丢弃 / 继续编辑”。保留不写业务库，丢弃只移除相应草稿；保存失败保持输入。磁盘写入失败会显示明确提示，不假装草稿已经安全保存。

提交继续经过 WriteQuickEntry/CommandExecutor：字段变化时更换请求编号，同一内容重复提交及进程恢复复用已落盘编号。新记录编号固定；恢复旧记录保留原所见版本，后来的内容修改或删除由原版本校验拒绝，不使用最新实体覆盖原版本。保存成功后只清理草稿；清理失败时锁住业务编辑，显示已保存并允许重试清理。

使用次数与最近使用时刻属于不增加内容版本的元数据。源码核对发现旧编辑对象可能把这两项回退，本批 saveEntryRaw 对已有条目保留数据库当前值，不改变内容版本与使用元数据的既有区分。

影响 L02/L03/L07，关联 N02/N03/N06/N09。无数据库或迁移变更，不增加运行时、Key 或网络依赖。

## 暂停的验收与限制

- 新建及编辑全部字段，包括时长0/超范围、空标题、标签、动作和归属，切换页面/模式与进程重启后恢复原输入。
- 保留、丢弃、继续编辑三条路径；取消不创建快捷项；一个草稿的丢弃不影响其他草稿。
- 多次点保存、写入成功但草稿未清理时退出或重启，只产生一个条目；清理失败提示与重试。
- 另一入口修改或删除后恢复草稿，原版本冲突不覆盖；期间使用条目，保存后次数和最近使用时刻不回退。
- 模态弹窗的返回顺序、200%字体、TalkBack及磁盘失败反馈。

以上均未执行。草稿只保存这个编辑器的输入，不保证其他计划子页或全部阶段2–5草稿已完成。模板、项目、周期和周目标仍逐项独立核对。同步小型偏好写入的真实设备交互与性能也未验收。
