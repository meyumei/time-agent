# T3.4 计划 Tab

计划页增加横向二级入口：

- 日程：月历概览，按月显示每天最多 3 条日程并显示其余数量。
- 任务：保留原计划首页任务、项目、周期和想法摘要。
- 截止、项目、周期：继续进入现有完整页面，保留原有编辑和操作入口。
