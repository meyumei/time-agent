# T3.4 计划 Tab

> 2026-11-04后续开发：日程页已复用共享时间轴，默认七日；五个子页在计划内切换。测试与手机操作按用户指令暂停，下面不是设备验收通过声明。

计划页增加横向二级入口：

- 日程：默认共享七日时间轴；1／3／7日、密度、过滤、列表、吸附使用计划独立偏好，与今天页分开；复用拖动、撤销、模板和提醒操作。
- 月历：月按钮打开，按可见42天范围查询；每天最多3个日程标题及其余数量，含提醒点、课表及跨日覆盖，实际记录继续在时间轴查看。点击任何日期进入该日一日视图。
- 任务：保留今天／即将／无日期／已完成分组、现有过滤、排序、快速添加及完整操作。
- 截止、项目、周期：在二级Tab下显示原完整页面，保留编辑、项目详情和周期作用范围流程；独立深链入口仍保留。
- 各子页通过独立保存区域保留其可保存的视图和滚动状态。月历跳转日期有独立请求序号，离开再返回不重复跳回旧日期。子模块仅存在于`remember`中的临时弹窗状态不会因此自动持久化，仍需后续统一草稿处理。
- 月历窄屏横向滚动，日期格去除外边距后的点击宽度至少48dp；星期与日期共同滚动。整格可点击，避免把3个标题做成过小按钮。

时间轴点条目保留详情面板。月历先进入一日时间轴，再查看条目详情。
