# T3.3 周期拖动的日期锚点修正

日期：2026-11-05。影响 L01、L06、L07，关联 N08。

## 源码定位与改动

按系统化排查流程追踪 `adjustTimelineRaw → saveRuleRaw → RecurringRules.expand`，确认两个独立的日期基准此前混用了：单个日程改动应从当前日程计算增量，后续规则与种子去重则应从实例原始日期计算位移。

- 例如每周一的 2026-11-09 实例先“仅此次”移动到 11-10，再移动到 11-11 并选择“此次及以后”。旧规则只偏移一天，会把后续规则改为周二；现在规则偏移按原始 11-09 至目标 11-11 计算，保留当前实例身份并对齐去重日期。
- 每月 31 日规则在 2026-11-30 的短月实例仅改变时刻时，继续保留 31 日锚点；每年 2 月 29 日规则在非闰年仅改变时刻时，同理保留闰日锚点。不把截断后的日期写回起始日期。
- 每周频次规则本来不设固定时刻。调整一个手动安排的实例时，后续规则保持空时刻、原始周桶和日期边界，不把同周其他 ordinal 当成重复实例取消。

未修改实体、schema、命令协议、手工例外保护和历史撤销实现。主代理核对现有事务、所见版本和保护实例路径；不凭静态核对宣称周期整项验收完成。
