# 通用 JSON 课表导入

这是本项目自有的交换格式，不是 WakeUp 分享格式，也不代表华工教务已适配。可以在“我的 → 导入 JSON 课表”中选择 UTF-8 JSON 文件。完整示例位于 `app/src/main/assets/course-import-example.json`；示例为合成数据，须预览并确认后才写入数据库。

- `sourceId`：稳定的导入来源标识，同一来源后续导入应保持一致。
- `sourceName`：显示名称。
- `term.id`：稳定学期 ID；`term.name`：显示名称。
- `term.firstWeekStart`：第一教学周的周一，`YYYY-MM-DD`。
- `term.teachingWeeks`：1–60。
- `term.timezone`：IANA 时区，例如 `Asia/Shanghai`。
- `periods`：学校实际节次，包含 `number`、`start`、`end`；时间为 `HH:mm`，由输入文件提供，应用不假定全国通用节次。
- `courses`：课程名称、教师、教室、星期（周一 1，周日 7）、起止节次、明确的教学周数组。单双周请展开为 `[1,3,5,...]` 或 `[2,4,6,...]`。
- `externalKey`：来源侧稳定课程 ID，可选。同一课程不同星期的课程行可使用同一 ID，实例按具体日期与时间分别去重。

导入前先完整解析和校验，再显示新增、已存在、受手工修改保护的实例数量。确认时在数据库事务内重新检查重复项。缺少节次、非法周次、非法时区或空课表会拒绝导入，原有数据不变。手工修改或取消的课程实例保留。

本轮采用保守的重复导入策略：已存在的来源实例跳过，不自动覆盖；更改源课程的时间可能生成新的候选实例。自动比对与合并来源更新将在取得真实教务样本后完善，不能将此路径当作学期全量同步。
