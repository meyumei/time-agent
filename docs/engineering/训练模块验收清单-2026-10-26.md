### UI/自动化可执行项

- [ ] **A1 动作库筛选**：操作：进入自由训练，搜索“深蹲”，依次切换器械、23大类肌群、仅置顶，再清空条件；预期：可检索本地1226个动作；每种筛选结果满足所选条件并与关键词取交集；置顶动作固定在前；清空后恢复全量列表。
- [ ] **A2 本地动图与自定义动作**：操作：断外网打开动作详情动图；新建自定义动作并搜索、添加；恢复联网重复；预期：动图从本地资源渲染且无外网请求；自定义动作可检索、添加、保存；断网与联网结果一致。
- [ ] **A3 多选编排**：操作：多选3个动作添加，替换第2个，使用上移/下移调序，移除第3个，保存后重进；预期：添加和替换只改目标位；顺序按操作保存；总数减1；重新添加被移除动作成功。
- [ ] **A4 组类型与负荷字段**：操作：分别新增热身、正式、递减、力竭组，录入重量×次数、自重加重、辅助重量、计时；预期：四种类型独立保存并回显；上述字段按类型可编辑并持久化；切换类型不把A类型数值写入B类型。
- [ ] **A5 有氧16字段**：操作：在有氧组录入16个字段，配速填5:30、心率填60.5、爬升填100；再填5:3、心率abc、爬升10.5；预期：首组合法值全部保存；非法值逐项提示且不落库；改回合法值后可保存。
- [ ] **A6 拉伸组**：操作：新建拉伸组，不填任何数字直接保存并结束该动作；预期：无数字必填阻断；可选数字留空可保存；补填数字后仍可保存。
- [ ] **A7 Tabata**：操作：配置准备5s、练20s、休10s、8轮并启动至结束；预期：按准备5s→练20s→休10s循环；第8轮练20s后直接结束，不再进入休息；中途暂停后恢复，剩余时间从暂停点继续。
- [ ] **A8 左右重量与容量×2**：操作：某组开启左右分开，左10kg、右12.5kg；切换容量×2开关；保存重进；预期：左右值独立保存；容量汇总随开关呈1倍/2倍变化；重进后开关与数值一致。
- [ ] **A9 RPE与文本**：操作：每组RPE依次填0、10、-1、11，填写组心得、动作笔记、训练心得；保存重进；预期：0和10保存，-1和11被拦截；三类文本分别挂在组、动作、训练层级，重进不串位、不丢失。
- [ ] **A10 休息**：操作：热身组休息设60s、正式组设90s，各结束一组；倒计时中点+15，再点跳过；预期：两类组进入各自休息时长；+15后剩余增加15s；跳过后立即进入下一组，同一休息不重复补触发。
- [ ] **A11 超级组容量**：操作：建A+B超级组，仅结束A时查看容量，再结束B；重复结束B一次；预期：A单独结束不计该轮容量；A+B齐后按整轮计一次；重复结束B不重复累加。
- [ ] **A12 总计时与单组秒表**：操作：开始训练，运行总计时后暂停，等待后继续；对单组启动、停止秒表；预期：暂停期间总计时不增加，继续后从暂停值累加；单组秒表独立计时，不影响总计时；重进页面读数一致。
- [ ] **A13 模板**：操作：新建含动作和Tabata配置的模板，编辑并保存，直接开练，返回删除并在确认框取消一次，再确认删除；预期：保存后可复用；开练带入动作与Tabata配置；取消删除保留模板；确认删除后列表移除且历史训练不受影响。
- [ ] **A14 结束写入**：操作：结束一次训练，填写实际时长、有氧、RPE、心得，点完成；预期：训练历史新增1条，主时间轴出现对应实际记录；两处字段与录入一致。
- [ ] **A15 重复完成**：操作：在A14基础上快速连点完成2次，返回列表再进详情；预期：训练历史和时间轴各只有1条对应记录；第二次点击不新增、不改写时间。
- [ ] **A16 时间轴失败恢复**：操作：注入时间轴写入失败后结束训练；预期：完整训练（组、有氧、RPE、心得）保留在历史或本地，出现可重试入口；恢复后重试，时间轴仅补1条，训练历史不重复。
- [ ] **A17 历史复训**：操作：选含重量次数、有氧、RPE、心得、Tabata配置的历史训练复训；预期：实际时长、有氧、RPE、心得清空；重量次数与Tabata配置保留；保存后生成新记录，旧历史不变。
- [ ] **A18 3D资源**：操作：断外网加载3Dbody，读取资源清单与渲染统计；预期：加载源为随包all.emg且哈希一致；mesh=3556、中文标签=3532、纹理=43；无外部资源请求和缺失占位。
- [ ] **A19 3D交互**：操作：单指拖拽、双指捏合、点选肌肉、隔离肌群、切换骨骼、全身复位；预期：分别产生旋转、缩放、目标高亮、仅目标肌群可见、骨骼显隐；复位后视角和缩放回到当前模式的默认位置。
- [ ] **A20 3D安全**：操作：构造外部http(s)地址、../路径、%2e%2e%2f编码路径请求；再加载合法本地资源；预期：外部请求被拦截，逃逸路径被拒且不读取包外文件；合法本地资源仍可渲染，页面不白屏。
- [ ] **A21 睡眠隔离**：操作：在睡眠模块新增并保存1条记录；再执行1次训练保存和1次3D加载；对照基线抓包、日志；预期：睡眠字段、请求和页面流程与基线一致；训练、3D操作不产生睡眠写请求或改写睡眠数据。
