# 训练模块实现说明

入口是“我的 → 健身训练 · 动作库 / 3D 肌群”，以及时间轴新建菜单中的“开始健身训练”。训练模块使用单独的 Activity 和 `workouts.db`，本轮不修改睡眠同步或主库 schema。

## 记录闭环

自由训练、模板或历史复训 → 按肌群/小部位/器械搜索选择动作 → 编排动作与训练组 → 记录重量、次数、计时或有氧数据 → 勾组并进入休息 → 完成训练 → 保留完整训练历史并回记时间轴实际记录。历史详情可复训、存模板；时间轴详情可返回完整训练。

训练标题、心得、动作笔记、每组 RPE/心得分层保存。支持正式、热身、递减、力竭组，左右重量与单侧容量设置，超级组，普通/热身分别设置休息。超级组整轮完成后才计入完成容量。热身组保留记录但不计正式容量。重量内部以 kg 保存，可切换 lb 输入显示。

八种记录类型分别为重量次数、自重附重、辅助重量、次数、时长、有氧、拉伸、Tabata。有氧保留原 16 个可选字段，包括字符串配速。配速和数字输入在失焦或键盘“完成”时提交，避免输入中间态触发校验。勾组和保存会先提交当前输入。拉伸可不填数字直接完成。

总训练计时、组间休息、单组秒表与 Tabata 都以持久化时间戳恢复，暂停时间不计入训练时长。Tabata 默认准备 5 秒、训练 20 秒、休息 10 秒、8 轮，最后一轮没有结束后的休息；可取消计时。模板能直接编辑阶段、组类型、递减段、左右设置、超级组和记录字段。

最小化后可通过训练通知返回。休息/阶段提示使用系统闹钟；未授予通知权限时不会有通知，未授予精确闹钟权限时锁屏提示可能延迟，设置页提供对应系统入口。当前没有持续运行的前台计时服务，系统休眠或强行停止应用可能延迟阶段提示；重新打开时按保存的时间戳恢复正确阶段。锁屏提示和杀进程恢复需要设备验证。

## 保存与恢复

每次编辑先在独立 Room 事务内保存，数据库唯一槽位保证只有一场进行中训练。完成先保存完整训练，再用稳定 ID `workout:<sessionId>` 回记时间轴；失败时保留详情和重试入口。主库的持久化请求标记防止崩溃重试、重复点击、用户手动删改时间轴后产生重复或复活记录。

历史复训清除实际计时、有氧、每组 RPE 和心得，保留重量次数与 Tabata 配置，重新生成训练/动作/组/超级组标识。上次数据也只取已完整完成的超级组轮次。

## 本地资源与 3D

动作库 1,226 条，1,211 份原始媒体（1,205 GIF、5 JPG、1 PNG），与原文件清单逐一核对 SHA-256。原数据有两个动作缺主图，显示动作占位图标；没有把远程讲解视频说成本地资产。Android 9 及以后用 ImageDecoder，Android 8 使用 Movie 动画回退。

3Dbody 接入真实 `all.emg`：3,556 个网格、3,532 个中文标签、43 张纹理。可以旋转、缩放、点选肌肉、高亮、隔离肌群和切换骨骼。静止时不持续绘制。使用自建 HTTPS 资源映射宿主页，只允许包内 anatomy 资源，拦截外部地址与目录逃逸；不加载原应用的会员、登录或远程接口。

资源与来源并非开源许可承诺，详见项目 `THIRD_PARTY_NOTICES.md`。完整原始模型/媒体清单及校验 JSON 在 `evidence/training-reverse-20261025/`。
