## 技术决策

采用新建精简项目：Kotlin、Compose、ViewModel/StateFlow、Room。业务规则置于纯 JVM `core` 模块，Android UI 和持久化置于 `app`。课程定义、课程实例、任务、计划块、实际记录各自独立。数据库保存 UTC epoch milliseconds，课程导入配置保存本地日期、节次和 IANA 时区，在规范化时转换为绝对时间。

## 本轮业务约定

- 所有区间采用 `[start, end)`，相邻不算重叠。
- 计划冲突返回提示，用户仍可保存；不自动移动安排。
- 实际记录允许重叠，统计同时给出累计记录投入和区间并集跨度。
- 只允许一个运行中的自动计时器，切换须明确确认；开始时间持久化，进程退出不依赖后台计数器。
- 任务软删除，关联历史保留；其计划不再显示，撤销后恢复。
- 编辑使用版本检查，撤销对比操作后快照，拒绝覆盖后续编辑。
- 实体版本使用独立的持久化递增计数；撤销和删除不回收已发出的版本，避免旧编辑页在撤销后误覆盖新数据。
- Room 不启用 destructive migration。v1 是新库基线；后续每次升级须提交显式 Migration、保留导出的 schema 并加入迁移测试。
- 本轮只提供明确标注的通用 JSON 导入路径和示例数据；真实华工教务解析仍待取得授权页面样本后验证。
