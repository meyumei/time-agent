# 课表导入说明与验证边界

课程来源使用应用自己的解析器。PDF 在设备内读取和提取文字；教务网页由用户在应用内的学校页面登录后，主动提取课表表格。课程导入沿用 `CourseNormalizer`、`TimeRepository.previewImport` 和 `commitImport`，继续使用事务、重复导入跳过和手工修改保护。

## PDF

支持华南理工大学教务导出的可选中文字的三列课表：星期、节次、课程详情。解析器读取 PDF 字符坐标和表格边界，保留跨行的星期、节次以及同一时段的单双周课程。周次支持连续区间、多个区间、单周、双周和“第 N 周”。

学期第一周周一和学校节次时间必须由用户核对。用户已指定本轮所有课程统一使用其 WakeUp 截图中的五山作息，不按课程校区分别换算。界面预填这一方案并提供“使用五山作息”按钮，仍可逐行修改；第 1–10 节按用户截图，第 11 节按学校公开作息索引的 20:50–21:35 作可修改参考。对应[学校作息表附件](https://www2.scut.edu.cn/_upload/article/files/8d/32/1dbbcf9a47729b8e2b85e4c02e01/a25ee229-19e8-4f09-afd5-3ea70b02bec6.pdf)本轮取回为 404，不能声称已下载核验，导入必须经过确认。

仅当解析出的学期标识为 `2026-2027-1` 时，根据[学校新学期开课新闻](https://news.scut.edu.cn/2026/0901/c41a60471/page.htm)预填第一教学周周一为 `2026-08-31`；新闻正文明确记载 8 月 31 日开课。其他学期不推断日期。课程行可修改、删除或补录；只写周数、未写星期和具体时段的实践课程会提示人工补全，不会自动排入日程。

图片扫描版、无法提取文字、加密限制或不支持的布局会显示原因，用户可切换手工补录。标准 0 / 90 / 180 / 270 度页面旋转会统一为视觉坐标后解析。此版本没有 OCR，也不会把普通文本文件当作 PDF。

测试资源 `app/src/test/resources/imports/scut-synthetic.pdf` 为重新生成的合成课表，不包含个人姓名、学号、课程名称或教师姓名。它保留合并单元格和周次组合，预期 16 行、周一至周四分别 3 / 6 / 2 / 5 行、共 145 次课程。真实用户 PDF 通过本机环境变量 `TIME_AGENT_TEST_PDF` 运行可选验收，文件与完整解析结果均不写入仓库。

真实 PDF 的 16 条课程已与独立 pdfplumber 提取逐行核对：名称、星期、节次、周次、教师、教室、校区和教学班标识全部相符（16 / 16 行，145 次上课，12 个教学班标识）。完整个人对照只保存在忽略提交的 `evidence/private-pdf-verification.json`。另有 0 / 90 / 180 / 270 度合成样本验证旋转后字形与表格线仍正确对齐。

## 华工官方教务网页

公开来源核验：

- [华工设计学院 2024-2025 学年第一学期选课通知](https://www2.scut.edu.cn/design/_t2289/2024/0625/c2818a557524/page.psp) 指向学生教务域名 `xsjw2018.jw.scut.edu.cn`，要求使用学校统一认证，说明校外访问可能需要学校 VPN。该通知给出的旧入口为 HTTP。
- [华南理工大学统一身份认证](https://sso.scut.edu.cn/cas/login) 是公开可读的官方 HTTPS 登录入口。

应用只允许明确列出的官方 HTTPS 域名，不降级 HTTP，不忽略证书错误，不处理验证码，不读取密码或 Cookie，不下载远程解析脚本。用户手动完成登录并进入课表页后，点击提取；应用只收集候选课表表格的副本，删除表单、输入框、脚本等元素后本地解析。退出导入网页时清理 WebView 会话。

自有 HTML 解析器覆盖带跨行单元格的星期/节次列表，以及按星期列展开的表格；同时保留自有正方 `kbList` 字段映射。它不是 WakeUp 私有脚本或公开 WakeUp API，也没有承诺所有正方版本通用。

本轮外网环境中，学生教务域名的 HTTPS 握手失败，未进行已认证的真实学校课表验证。学校可能要求校内网络或 VPN，当前认证后的页面和重定向仍需在用户设备上验收。网页失败时可使用已验证的 PDF 路径或手工补录。

## 第三方库

- [PdfBox-Android](https://github.com/TomRoush/PdfBox-Android)：`com.tom-roush:pdfbox-android:2.0.27.0`，Apache-2.0；用于真实 PDF 文字及表格线提取。限制文件大小、页数和文字数量，避免无界解析。
- [jsoup 官方下载说明](https://jsoup.org/download)：`org.jsoup:jsoup:1.23.2`，[MIT 许可证](https://jsoup.org/license)；只解析已取得的 HTML，不执行页面脚本。
