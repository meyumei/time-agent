# 语音助手 v1

官方文档读取日期：2026-10-20。

## 官方接口依据

- [Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)：创建、监听、停止、取消、销毁在主线程；释放时调用 destroy；Android 11 及以上需要 RecognitionService 查询声明；每轮识别结束或出错之后才允许再次启动。
- [Android Keystore](https://developer.android.com/privacy-and-security/keystore)：AES 密钥由 AndroidKeyStore 保存，应用持有 API Key 的加密内容；耗时的密钥操作在后台线程执行。
- [DeepSeek 首次 API 调用](https://api-docs.deepseek.com/)：固定官方端点 `https://api.deepseek.com/chat/completions`，Bearer 鉴权，非流式响应。读取时官方默认示例模型为 `deepseek-flash`（DeepSeek V4.1 Flash 1017）；模型名允许在应用中编辑，避免官方调整后必须重新安装。
- [DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)：请求声明 `response_format: {"type":"json_object"}`，提示词包含 JSON 示例；仍须拒绝空内容、截断和不合要求的返回值。
- [DeepSeek 错误码](https://api-docs.deepseek.com/quick_start/error_codes/)：网络、鉴权、额度、限流或服务异常都显示失败，不把它们转换为保存成功。

## 使用边界

助手每次处理一个动作，0.3.1 增加整批取消内置示例课程这一固定范围操作。新建计划需要已存在的任务。首页底部按住说话，顶部实时显示文字；松开识别，上滑取消。首次准备模型或授权后须重新按住。识别结果位于助手上方可编辑输入框，保存仍须明确确认；同音候选须点击才采用。右上角键盘可直接输入，读屏提供开始、显式结束和取消动作。

0.3.1 默认使用 APK 内置 Vosk 中文模型，无需设备提供系统语音服务。采集和识别各自独立工作，音频只在本次内存队列中存在，不保存、不上传，不在后台监听；单次录音上限 60 秒，停止采集后继续整理已录入内容。模型归档先校验 SHA256，再解包到应用 noBackup 目录。系统语音适配器保留为开发兼容接口，不是默认用户路径。

本地常用命令无需 DeepSeek API Key。自由表达可在助手设置中填写自己的 API Key，并在当次使用前同意发送当前文字和有限清单；发送前可查看实际上下文。默认不发送任务描述、实际记录备注、操作历史或整段会话。API Key 仅通过应用内输入，以 Android Keystore AES/GCM 加密后保存在设备，源码和构建文件不含用户 Key。

写入必须经过具体预览与确认；未来的实际记录需要单独勾选确认。取消预览不会写库。修改携带实体版本；旧预览不能覆盖后续修改。重复确认同一预览只写一次。助手只接受白名单操作及严格参数，模型不能运行任意代码、SQL、网络地址或工具。

取消云端请求会断开当前连接。过期请求的结果和结束回调不能覆盖后来发起的请求；关闭助手也会取消未完成的请求。任务、冲突列表和运行计时的版本核对与最终写入位于同一个数据库事务内。

## 本地示例

- `今天有什么安排`、`明天有什么安排`、`本周有什么安排`、`查看任务`
- `明天有什么空闲`（默认在 08:00–22:00 中查找至少 30 分钟的空段）
- `新建任务 论文阅读 一小时三十分钟`
- `安排 明天 19:00 到 20:30 论文阅读`（任务需已存在）
- `安排 周五 19:00 论文阅读 半小时`（周几以界面所选周为准）
- `记录 今天 14:00 到 15:00 阅读`
- `开始计时 论文阅读`、`停止计时`
- `取消任务 论文阅读`、`取消计划 论文阅读`
- `取消示例课程`、`删除所有示例课程`、`帮我清理一下示例课表`：列出整个内置示例学期的课程和次数，经确认后取消；真实导入课程不纳入。一次撤销恢复整批。
- `修改任务 论文阅读 为 文献阅读`、`修改任务 论文阅读 时长 45分钟`
- `移动计划 论文阅读 到 明天 19:00 到 20:00`

相同名称有多个任务或计划时会要求明确身份；缺少时间、起止倒置、跨天未明确日期、复合操作等情况不会猜测并写入。日期支持今天、明天、后天、昨天、YYYY-MM-DD、周一至周日（含本周和下周），时间支持 HH:mm 和明确的中文时点。输入无法可靠解析时，保留原文供修改。

## 验证说明

仓库包含录音失败复位、实时转写、取消与晚到结果、采集与识别解耦、本地解析、严格云端协议、写入确认门控及真实 Room 集成测试。使用相同中文模型的桌面原生识别验证记录包含原始误识别和候选，不能替代手机麦克风实测。用户截图已展示 DeepSeek 实际响应，开发环境未读取用户 Key。
