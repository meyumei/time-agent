# T4.3 提醒入口

提醒保留原有闹钟、开机、时区变化、时间变化、更新和精确闹钟权限恢复流程，并新增通知操作：

- 完成：若提醒关联任务，沿用任务版本检查完成任务；无关联任务只关闭当前通知。
- 稍后 10 分钟：以稳定提醒 ID 和当前版本重新保存提醒，交给现有协调器重新登记。
- 开始计时：关联任务直接调用 `TimeRepository.startTimer`；没有关联任务时打开提醒详情。

所有通知按钮都使用提醒 ID 与动作组成的 PendingIntent requestCode；通知写入和计时写入仍经过现有 Repository/CommandExecutor 路径。
