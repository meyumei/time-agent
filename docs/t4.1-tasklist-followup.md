# T4.1 任务、截止、项目与周目标后续开发

日期：2026-11-04。分支：`codex/t4.1-tasklist-followup`。

本批按用户要求只开发与编译，没有运行测试、lint 分析或操作手机。收到安全检查点暂停要求后，收回现有 DS 产物，停止派发新任务；本提交不代表阶段 2–5 完成或设备验收通过。

## 本批代码

- 任务列表支持项目与标签共同筛选、截止／优先级／手动排序、已完成折叠；显示偏好和各筛选范围内的手动顺序保存在本地。
- 左滑安排时间、右滑完成，原按钮和菜单保留；右滑已完成任务不会恢复任务。
- 快速输入在本地预览日期、精确匹配的项目与标签，确认后打开预填编辑器。歧义保留完整原句，输入和预览均不写业务库。
- 任务编辑器增加项目、多标签、无／低／中／高优先级。旧 0／1／2 语义保留，新增 -1 表示无优先级；主库仍为 v22，备份内容校验同步接受该值。
- `WriteTaskDetails` 将任务、项目归属、标签以及可选新日程放在同一命令事务与撤销组中。保存核对任务版本、所见归属版本和标签集合；标签或项目已删除时明确拒绝保存。
- 任务保存、完成与恢复显示撤销提示；完成不生成实际记录。原公开任务保存方法也接入命令执行器；新建并安排使用稳定请求编号。
- 新增 `WriteProject`，项目保存／删除、任务归属与周目标保存经由统一命令执行器，保留原历史恢复逻辑。
- 截止概览包含普通任务截止与生活期限的下一待处理实例，去重后分已逾期／今天／3 天内／更远，并提供关联任务、安排时间和完成操作；生活期限规则、延期、已处理历史与提醒状态保留。
- 项目列表卡片显示本周投入、目标和进度。下一步任务的实际时长按真实工作片段计算，不把专注暂停和休息计入；保留原来累计投入的时间范围。
- 项目弹窗与输入使用可保存状态；打开的项目对象保存完整字段和所见版本。周目标保存使用打开表单时冻结的目标快照，不从提交时最新数据取得版本。

## 恢复工作时的验收步骤

以下均尚未执行：

1. 创建项目与标签，快速输入“明天交报告 #项目名 #标签名”，核对预览、编辑预填及一次保存结果；歧义名称保持纯标题。

5. 专注暂停后继续，核对项目周投入和累计投入排除间隙；切 Tab、重建 Activity 后保留项目草稿及所见版本。
