# 3. 逐页规格与核心交互

> 📱 本章逐页定义元素、状态与交互。每页按“结构 → 元素 → 交互 → 状态（空/加载/错误/权限）→ 验收”书写。坐标、尺寸使用第 2 章 Token。“拟建”路由与组件名可由 Codex 调整，但行为不可改。

## 1. 今天（`today`）

### 1.1 结构（自上而下）

1. **顶栏**：日期（“10月31日 周五”），右侧：鱼状态头像（点按进入鱼聊天）、溢出菜单（跳转日期、时间轴设置）。
2. **计时条**（有运行中计时时出现，吸顶）：名称、已用时长（每秒更新，**只在此组件内订阅秒级时钟**）、按钮“停止”“切换”；无计时时显示“开始计时”按钮＋最近 3 个常用项芯片（来自 N09 快捷记录）。
3. **问候/简报区**：工具模式一行摘要；陪伴模式鱼气泡。点按展开完整简报（L19）。可折叠，折叠状态持久化。
4. **待处理卡片**（横向可滑，最多 5 张，按优先级）：即将开始的日程（30 分钟内）、今天到期的截止、待确认草稿（记账/语音/收件箱）、建议（L18）、未完成的专注。每张卡片一个主操作＋关闭。
5. **时间轴**（占剩余高度）：默认三日视图（见 §1.3）。
6. **FAB**：新建菜单。

### 1.2 FAB 新建菜单

点按弹出 4 项：新建日程、新建任务、补录实际、开始专注。长按 FAB = 直接新建日程（以当前时间向上取整到 15 分钟为开始，时长 60 分钟）。

### 1.3 时间轴（今天与计划共用组件 `TimelineView`，拟建）

**视图模式**：分段按钮 1 日 / 3 日 / 7 日（位于时间轴顶部工具行左侧）。

| 项目 | 1 日 | 3 日（默认） | 7 日 |
| --- | --- | --- | --- |
| 显示范围 | 选中日 | 选中日前一天、选中日、后一天（选中日居中） | 选中日所在周（按一周起始日设置） |
| 每列内容 | 计划轨＋实际轨并排 | 每日一列，列内左计划右实际 | 每日一列，计划/实际叠加显示（实际为实心，计划为描边） |
| 列最小宽度 | 全宽 | 屏宽/3 | 48dp；不足时横向滚动，不压缩字号/按钮 |
| 块内文字 | 标题＋时间＋标签 | 标题＋时间 | 仅标题（可省略）；高度 < 24dp 不显示文字 |

**工具行**（替换现有拥挤工具栏）：左：1/3/7 分段；中：“今天”按钮（不在今天时出现）；右：密度按钮（放大/缩小）、过滤图标（计划/实际/课表/健康睡眠可见性）。全部 48dp。其余设置进溢出菜单。

**两轴拆分**（修改 `core/TimelineViewport.kt`）：
- 横向：天数（1/3/7）与当前首日；左右滑动按“视图天数”翻页（3 日视图滑一次移动 1 天还是 3 天：**移动 1 天**，保证今天可回到中间；7 日视图移动 7 天）。
- 纵向：密度 `hourHeightDp`，默认 64，范围 32–160，双指捏合只改纵向；“全天概览”按钮一键设为可容纳 0–24 点的密度。
- 初次进入：纵向滚动到“当前时间 − 1 小时”；如今天不在范围内则滚动到 08:00。
- 切换 1/3/7：保持选中日和纵向锚点（屏幕中线对应的时刻）不变。
- 用户主动选择 1 或 7 日后保存偏好；从后台返回或跨天时**不跳走**，只在用户点“今天”时重新居中。
- 跨午夜：0 点自动刷新“今天”标记，但不改变用户当前查看的范围。

**元素**：
- 当前时间线：主色细线＋圆点，每分钟更新（不是每秒）。
- 冲突：重叠的计划块并列分栏显示（保留现有 `TimelineConflicts.kt`/`ConflictGroupAppearance.kt` 算法），顶部有冲突图标。
- 实际记录可重叠：并列分栏，不当作错误。
- 全天日程：时间轴顶部“全天”行，每个全天日程一个芯片。
- 提醒点：在对应时刻显示圆点＋小旗标，不占时长。
- 课表：作为计划轨的一种来源，带来源图标，可在过滤中隐藏。
- 健康睡眠：作为实际轨的只读来源（来自 L09），带来源图标。

**交互**：

| 手势 | 结果 |
| --- | --- |
| 点按空白 | 在该时刻（吸附 15 分钟）创建 60 分钟日程草稿，打开日程编辑器（未保存不写库） |
| 长按空白并拖动 | 框选时间范围，松手后打开编辑器，预填范围；可选“计划/实际” |
| 点按块 | 打开 `DetailSheet` |
| 长按块 | 进入移动模式（触感反馈），拖动改变开始时间（可跨列跨天） |
| 拖动块上/下边缘手柄 | 调整开始/结束（N08，详见第 5 章） |
| 双指捏合 | 纵向密度 |
| 左右滑动（非拖拽中） | 翻页 |

拖拽通用规则：预览过程不写库；松手一次提交；吸附 5/15/30 分钟（默认 15，设置可改）；拖拽中按下第二指或按返回键 = 取消本次拖拽并恢复原位；提交时检查版本，冲突走版本冲突流程；提交后 Snackbar“已移动到 14:15–15:15 · 撤销”。

### 1.4 详情面板（`DetailSheet`）

- 标题、类型标签（日程/实际/任务）、时间（含时长与时区，仅当时区与设备不同才显示）、关联任务/项目、重复摘要、提醒、备注、附件缩略图、来源（手动/鱼/语音/课表/日历/健康）。
- 主操作（最多 2 个）：日程→“开始计时”“编辑”；实际记录→“编辑”“继续计时”；任务→“完成”“编辑”。
- 溢出菜单：复制、移动到…（日期选择）、转为实际/转为计划、删除、查看历史、稍后提醒（N07）。
- 由鱼创建的条目显示“由大肥鱼创建 · 查看对话”链接，跳回对应聊天消息。

### 1.5 状态

- 空：今天无日程 → 时间轴中间 `EmptyState`“今天还没有安排”＋“添加日程”；不隐藏时间轴。
- 首次启动且选了示例数据：显示示例数据横幅“这是示例数据 · 清除”。
- 通知权限缺失且存在提醒：`StatusBanner`“提醒可能不会弹出 · 去开启”。
- 精确闹钟权限缺失（Android 12+）：同上，文案区分。

### 1.6 验收

- 冷启动到时间轴可交互 ≤ 1.5 秒（中端机，1 万条记录；见第 6 章性能基线）。
- 计时条秒级更新时，Layout Inspector 显示时间轴不重组。
- 1/3/7 切换保持锚点；后台 10 分钟返回不跳动。
- 200% 字体下工具行无重叠。

## 2. 计划（`plan`）

### 2.1 结构

顶部二级切换（可横滑的 Tab 行）：**日程 / 任务 / 截止 / 项目 / 周期**。课表不单独成 Tab：显示在日程时间轴中，管理入口在管家 → 课表。

### 2.2 日程

- 默认与今天页同一 `TimelineView`，但默认 7 日（用户可改，独立偏好）；顶部有“月”按钮打开月历（月视图：每日显示最多 3 个日程标题＋“+N”；点日期进入该日 1 日视图）。
- 列表模式开关：按日期分组的列表，无障碍等价视图。

### 2.3 任务

- 分组：今天 / 即将 / 无日期 / 已完成（折叠）。可按项目、标签筛选；排序：截止、优先级、手动。
- 列表项：勾选框（48dp）、标题、截止标签、项目色点、子任务进度。勾选 = 完成＋Snackbar 撤销；**不生成实际记录**。
- 左滑：安排到时间轴（打开日程编辑器并关联该任务）；右滑：完成。滑动有等价溢出菜单项。
- 快速添加栏（底部）：输入“明天交报告 #课程”，用本地指令解析器预览解析结果（日期/项目芯片），回车创建；解析失败按纯标题创建。

### 2.4 截止

- 按紧急程度分区：已逾期 / 今天 / 3 天内 / 更远。保留 `DeadlineStatus.kt` 状态计算。
- 每项：剩余时间、关联任务进度、“安排时间”按钮（为该截止创建日程块）。

### 2.5 项目

- 卡片：名称、颜色、进度（`projects/ProjectProgress.kt`）、本周投入时长、周目标完成度（L20）。
- 项目详情：任务、日程、实际时长趋势、项目复盘（`ui/ProjectReview.kt`）。

### 2.6 周期

- 规则列表：可读摘要、下次实例、状态（启用/暂停）。
- 规则编辑：使用 `RecurrenceField`；修改规则时询问作用范围：“仅以后的实例 / 包括已生成但未完成的实例”；**已有手工例外（`manualOverride`）的实例永不被覆盖**，并在确认面板中列出受影响数量。
- 实例操作：跳过本次、改到别的时间（生成例外）、完成。

## 3. 语音面板（`VoiceSheet`）

### 3.1 打开方式

- 点按中央按钮：打开半屏面板并开始收音（若已授予麦克风权限）。
- 长按中央按钮：按住说话，松开结束；上滑取消。以现有 `HoldToTalkButton.kt` / `HoldToTalkSession.kt` 的手势与会话逻辑为基础改造，不另写一套。
- 通知栏/小组件的“语音记录”也打开此面板。

### 3.2 流程与状态机

`Idle → Listening → Finalizing → Interpreting → Preview → Committed | Cancelled | Failed`

1. Listening：Vosk 实时预览转写显示为灰色文字；波形/鱼聆听动画。
2. Finalizing：SenseVoice 终稿替换预览；**终稿只提交一次**；如果用户已开始手动编辑文本，迟到的终稿不覆盖，而是在文本框上方提示“识别结果已更新 · 使用”。
3. Interpreting：路由规则（见第 7 章 §3）：先本地指令解析；命中则产生结构化预览；未命中且鱼可用则交给鱼；鱼不可用则提供“存入收件箱”“作为任务标题”等本地选项。
4. Preview：显示解析卡片（例如“新建日程：明天 14:00–15:00 组会”），可编辑每个字段；按钮“确认”“修改”“交给大肥鱼”。
5. Committed：写入并 Snackbar 撤销；面板可选择保持打开继续说下一句。
- 低风险本地指令（开始/停止计时、查询）可在设置中开启“免确认直接执行”，默认关闭；写入类始终可撤销。

### 3.3 错误与权限

- 无麦克风权限：面板显示原因＋“授予权限”；拒绝后提供文本输入框，不阻塞。
- 离线识别模型缺失（`OfflineModelFiles.kt`）：提示下载/使用 Android 系统语音输入作为替代。
- 识别为空：“没有听清”＋“重试”。

## 4. 复盘（`review`）

### 4.1 结构

顶部分段：**日 / 周 / 月**；下方日期切换（左右箭头＋点击日期选择）。内容区块：

1. **总览**：计划时长、实际时长、计划完成率、专注时长、睡眠时长（有数据时）。
2. **计划 vs 实际**：按天/按项目条形对比。
3. **分类分布**：按项目/标签占比。
4. **习惯统计**（N10）入口卡片。
5. **报表**（N05）：生成周报/月报、导出。
6. **问答**（L17）：“问问你的历史”，输入问题；本地可回答的统计类问题本地回答，其余交给鱼。
7. **建议**（L18）：基于本期数据的建议，可一键执行（转为日程/任务）。

### 4.2 统计口径（必须在 UI 中可见：点 ⓘ 显示）

- **累计时长**：所有实际记录时长之和，可超过 24 小时（重叠计多次）。
- **覆盖时长**：实际记录区间的并集，最多 24 小时/天。两个数字同时展示，标注清楚。
- 运行中的计时：裁剪到当前时刻计入。
- 跨天记录：按自然日边界切分计入各日；夏令时等时区变化按实际时刻差计算。
- 睡眠：来自健康来源，多来源重叠时按 L09 去重规则；无数据显示“无数据”，不当 0。
- 每个数字可点进明细列表，追溯到具体记录与来源。

## 5. 管家（`butler`）

### 5.1 结构

1. **顶部**：设置入口（齿轮）、模式快速切换（工具/陪伴）。
2. **鱼卡片**：头像/角色、运行时状态（已就绪/启动中/未启动/需要 Key/仅本地）、最近一条消息、按钮“聊天”“语音”。点击卡片进入鱼主页。
3. **生活模块网格**（2 列，每格 图标＋名称＋一行状态）：训练（今日/上次训练）、记账（本月支出、待确认数）、健康（昨晚睡眠/同步状态）、课表（今天课程数）、附件、收件箱（未处理数）、工具（聊天提取、回复副驾）。
4. **个人规则与记忆**入口。

### 5.2 鱼主页（`butler/fish`）

二级菜单（列表，不超过两层）：
- 聊天（L23）
- 记忆与规则（共同记忆 L27 ＋ 个人规则 L16，分两个分区，明确标明“共同记忆由大肥鱼维护”“个人规则由你设定”）
- 主动关心（L28）：开关、频率、允许时段、免打扰
- 平台（L29 QQ、L30 B 站）：各平台连接状态、自主活动开关与范围/频率/时段（新安装默认关闭，开启时说明会以你的账号做什么）
- 声音（L26）：Edge 朗读开关、音色、语速；鱼语音
- 悬浮窗（L25）：开关、悬浮窗权限状态、尺寸、透明度、点击行为
- 角色（L24）：形象展示与陪伴玩法
- 运行时（L31）：状态、启动/停止、日志、存储占用、重装 rootfs、诊断

### 5.3 鱼聊天页

- 消息列表＋输入框＋语音按钮＋贴纸。
- 输入框草稿在离开页面、切换模式、进程重启后保留。
- 运行时未就绪时：顶部 `StatusBanner` 显示状态与“启动”；输入仍可发送——本地指令立即执行；其余消息进入“待发送”队列，显示时钟图标，就绪后按顺序发送，可单条取消。
- 工具调用结果以卡片展示（“已创建日程 明天 14:00 组会 · 查看 · 撤销”）。
- 生成中可“停止生成”；停止不回滚已经提交的工具动作，卡片仍显示已执行并可撤销。

## 6. 编辑器

### 6.1 日程编辑器（全屏，或大屏半屏面板）

字段顺序：标题（必填，自动聚焦）→ 类型（时段/提醒点/全天，分段）→ 时间（`DateTimeRangeField` / `DateTimeField` / `DateField`）→ 重复（`RecurrenceField`）→ 提醒（`ReminderField`）→ 关联任务（`EntityPicker`，可空）→ 项目/标签 → 颜色 → 备注 → 附件。

- 底部固定“保存”；顶栏左侧关闭（有修改时询问保留草稿/丢弃）。
- 冲突提示：时间字段下方显示“与 2 项重叠”可展开，不阻止保存。
- 跨午夜：结束时间早于开始时，`InlineError`“结束早于开始”＋开关“结束于次日”。
- 草稿：编辑器打开期间每 2 秒（防抖）保存草稿到本地；被系统杀死后重新进入提示“恢复未保存的编辑”。

### 6.2 任务编辑器

标题、备注、截止（日期＋可选时间）、优先级（无/低/中/高）、项目、标签、子任务（可拖拽排序）、重复、提醒、附件。底部“保存”；顶部“安排时间”。

### 6.3 实际记录编辑器

标题/关联任务、开始/结束（`DateTimeRangeField`，结束可为空表示进行中——仅当没有其他主计时运行）、项目、备注、来源（只读）。

### 6.4 校验规则

| 字段 | 规则 | 错误文案 |
| --- | --- | --- |
| 标题 | 去首尾空格后非空，≤ 200 字 | “请输入标题” |
| 时段 | 结束 > 开始；时长 ≤ 7 天（超过需确认） | “结束早于开始” |
| 提醒点 | 只有一个时刻 | — |
| 全天 | 起止日期，结束 ≥ 开始 | “结束日期早于开始日期” |
| 重复 | 结束条件有效 | “重复结束日期早于开始” |
| 提醒 | 提醒时刻在过去：允许保存，提示“这个提醒时间已过，不会再提醒” | — |
