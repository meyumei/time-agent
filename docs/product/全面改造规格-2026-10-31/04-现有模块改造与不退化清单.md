# 4. 现有模块改造与不退化清单

> 🧩 本章逐个说明现有模块“保留什么、改什么、怎么验收”。编号对应第 1 章功能保留账本（L01–L36）。每个模块的改造都必须先通过统一执行入口（第 6 章 §4）写数据，并接入统一组件（第 2 章 §4）。

## 通用改造动作（适用于所有模块）

1. 页面迁入导航图（或保留 Activity 但统一主题/顶栏，见第 2 章 §1.3）。
2. 字符串迁入 `strings.xml`。
3. 日期时间输入换为 `DateField/TimeField/DateTimeRangeField`。
4. 写操作改为调用领域用例（UseCase）→ 统一执行入口，返回结构化结果；删除支持撤销。
5. 读操作改为按需 Flow 查询（不再依赖全量 `LocalSnapshot`）。
6. 错误/空/加载/权限状态按第 2 章 §4.1。
7. 在账本中更新证据。

## L01–L02 时间轴与计时

**保留**：计划/实际分离、实际可重叠、冲突允许保存、撤销重做、乐观锁版本、历史记录、冲突分栏算法（`TimelineConflicts.kt`、`ConflictGroupAppearance.kt`）、渲染缓存（`TimelineRenderCache.kt`）、配色（`TimelinePalette*.kt`）。

**改造**：
- `core/TimelineViewport.kt`：拆为 `HorizontalRange(dayCount ∈ {1,3,7}, firstDay)` 与 `VerticalScale(hourHeightDp 32..160)`；删除 `FIT_DAYS=7` 隐含默认，改为偏好（默认 3）。保留现有纯函数测试并新增：锚点保持、翻页、跨月、跨夏令时日、一周起始日。
- `ui/Timeline.kt`：拆分为 `TimelineToolbar`、`TimelineCanvas`、`TimelineGestures`、`AllDayRow`；移除 `LocalMinimumInteractiveComponentSize provides 0.dp`。
- 秒级时钟：新增 `ClockSource`（拟建），提供 `minuteTicks`（时间线）与 `secondTicks`（只给计时条/专注界面），根组件不再收集 `now`。
- 计时：同一时刻只允许一个“主计时”（自由计时、专注、训练三者共用一个槽位，见第 5 章 N03 冲突规则）；进程被杀后由数据库中 `end=null` 的记录恢复。
- 补录：入口统一在 FAB 菜单“补录实际”和时间轴长按框选。

**验收**：账本 L01/L02 全项；拖拽、撤销、版本冲突用例真机录屏；时间轴 1 万条数据下滑动无明显掉帧（见第 6 章性能基线）。

## L03–L05 任务、截止、项目

**保留**：全部字段、状态、项目归属、截止状态计算、项目进度与复盘。

**改造**：
- 任务完成不自动生成实际记录（若现有代码有此行为，需在 T0 记录并与用户确认后改；若没有则保持）。
- 列表滑动操作与溢出菜单等价。
- 截止“安排时间”按钮：创建关联该任务的日程（日程 `taskId` 有值）。
- 项目卡片显示周目标完成度（L20）。

**验收**：创建/编辑/完成/恢复/删除撤销；截止分区正确（含时区、跨天）；项目复盘数字与复盘页口径一致。

## L06 周期事务

**保留**：`RecurringRuleEntity`（patternJson、domain、projectId、version 等）与 `RecurringInstanceEntity`（ruleId、taskId、originalDate、ordinal、status、manualOverride、ruleSnapshot、ruleVersion、taskVersion、planVersion 等）全部字段与语义；`recurring/RecurringService.kt`、`RecurringValidation.kt` 逻辑。

**改造**：
- 编辑 UI 换为 `RecurrenceField`；规则 JSON 结构不变，新增字段需走迁移。
- 修改规则时的作用范围询问（第 3 章 §2.6）；手工例外永不覆盖；变更前显示受影响实例数。
- 周期日程（N07 重复提醒、N04 日历同步）复用同一规则模型，不另建第二套重复引擎。

**验收**：现有周期测试全部保留；新增：修改规则不影响 manualOverride 实例、ruleSnapshot 保留历史、跨月末（31 日）与闰年 2 月 29 日。

## L07 提醒

**保留**：`reminders/ReminderAlarms.kt`（AlarmManager 精确闹钟）、`ReminderNotifications.kt`、`ReminderReceivers.kt`、`NotificationAccess.kt`。

**改造**：
- 精确提醒继续用现有 `setExactAndAllowWhileIdle`（无精确闹钟权限时现有代码降级为 `setAndAllowWhileIdle`，保留该降级并在 UI 提示“可能延迟”）；可延迟任务（同步、报表生成、清理）改用 WorkManager。
- 开机、时区变更、时间变更、App 更新后重排所有未来提醒。Manifest 中已有 `BOOT_COMPLETED`/`MY_PACKAGE_REPLACED`/`TIME_SET` 接收器（一个接收器还含 `TIMEZONE_CHANGED`）；T0 核对每类提醒（日程、截止、周期、训练）是否都被重排，缺失的补齐。
- 通知操作按钮：完成、稍后提醒（N07）、开始计时。
- 权限：Android 13+ 通知权限、Android 12+ 精确闹钟权限；缺失时在设置和相关页面显示 `StatusBanner`。

**验收**：锁屏、Doze（`adb shell dumpsys deviceidle force-idle`）下提醒按时；重启后提醒仍在；改时区后提醒按“墙上时间”或“绝对时刻”规则（日程保存时记录时区，默认按日程时区）。

## L08 课表

**保留**：JSON（`data/JsonCourseAdapter.kt`）、PDF（`imports/PdfTimetableExtractor.kt`、`ScutPdfTimetableParser.kt`）、华工教务（`imports/OfficialSchoolImport.kt`、`OfficialTimetableParser.kt`、`ScutImportPresets.kt`）三种导入；导入预览（`CourseImportDraft.kt`）、去重、手工修改；`SampleCourseScope.kt`。

**改造**：
- 入口：管家 → 课表；课表视图（周视图网格）＋导入向导（选来源 → 预览差异：新增/更新/删除 → 确认）。
- 课程在计划时间轴中作为来源“课表”显示，可隐藏；点按课程显示详情（教室、教师、周次），可“为这节课添加任务”。
- 重新导入时，手工修改过的课程标记“已手工修改”，默认不覆盖，预览中可逐条选择。

**验收**：三种来源各一份样例导入；重复导入不产生重复；手工修改保留。

## L09 健康

**保留**：Health Connect（`health/HealthConnect.kt`、`HealthConnectReader.kt`）、Gadgetbridge 导入（`GadgetbridgeImporter.kt`）、读取报告（`HealthReadReport.kt`）、`Nudge.kt`；睡眠多来源去重；缺失不当零。

**改造**：同步状态卡片（上次同步时间、来源、失败原因）；复盘中睡眠数据可追溯来源；权限被撤销时显示 `StatusBanner`。

**验收**：两个来源重叠睡眠只计一次；无数据显示“无数据”；撤销权限后不崩溃并提示。

## L10 记账

**保留**：`ledger/*` 全部：支付通知监听（`PaymentNotificationListener.kt`，默认关）、解析（`PaymentParser.kt`）、草稿待确认、金额整数分、CSV 导出、合并/拆分。

**改造**：
- `LedgerActivity` 统一主题与顶栏（阶段一），后迁入导航（阶段二）。
- 待确认草稿在今天页待处理卡片与管家网格中显示数量。
- 金额输入组件：数字键盘，显示两位小数，内部存分；禁止浮点运算。
- 通知监听开启流程：说明会读取哪些 App 的通知、仅本机处理，再跳系统设置。

**验收**：CSV 导出与现有格式兼容；合并/拆分后总额不变（单测）；通知监听关闭时不产生草稿。

## L11 训练（完整保留，不得简化为计数器）

**保留**：`workout/*` 与独立数据库 `workouts.db`：动作库与 GIF（`WorkoutCatalog.kt`、`WorkoutGifDrawable.kt`）、3D 肌肉（`WorkoutAnatomy.kt`）、8 种记录类型、4 种组类型、4 种训练状态、超级组、Tabata、模板（`WorkoutTemplateEditor.kt`）、组间休息计时、训练通知（`WorkoutNotifications.kt`）、动作选择器（`WorkoutPicker.kt`）。

**改造**：
- 统一主题/顶栏；训练进行中在今天页计时条显示“训练中 · 已 32 分钟”，点击回到训练会话。
- 训练与主计时槽位互斥规则（第 5 章 N03）：开始训练时若有自由计时，询问“结束当前计时并开始训练 / 取消”。
- 训练完成后生成一条实际记录（来源=训练，关联训练会话 ID），只生成一次（幂等）。
- 训练库纳入统一备份 v2（第 6 章 §6）。

**验收**：8 种记录类型各录一组；超级组、Tabata 完整流程；PAUSED 后进程被杀恢复；训练生成的实际记录不重复。

## L12–L15 附件、收件箱、聊天提取、回复副驾

**保留**：附件存储与 OCR、关联条目；收件箱收集与分拣；聊天提取（`extraction/*`）；回复副驾（`reply/*`）。

**改造**：
- 收件箱分拣统一为“转为：任务 / 日程 / 记账 / 记忆规则 / 删除”，每项打开对应编辑器预填。
- 聊天提取结果先进入预览（与语音 Preview 同一组件），确认后写入。
- 回复副驾需要模型：鱼/Key 不可用时显示原因与“去设置”，不隐藏入口。
- 附件：详情页缩略图；大文件（>20MB）提示；OCR 失败可重试。

**验收**：各入口可用；无 Key 时提示正确；附件纳入备份并可恢复。

## L16–L20 个人规则、历史问答、建议、简报、周目标

**保留**：全部现有能力。

**改造**：
- 个人规则与共同记忆在 UI 上分区（第 3 章 §5.2），存储不合并。
- 历史问答：统计类问题（“上周学习多久”）由本地查询直接回答并展示明细链接；开放问题交给鱼，带上本地查询结果作为工具返回。
- 建议：每条建议有“执行”（转为结构化草稿预览）与“不再提示此类”。
- 简报：今天页顶部；生成失败时显示本地版（今日日程数、截止、昨日实际时长）。
- 周目标：复盘周视图与项目卡片显示完成度。

## L21–L22 语音与本地指令

**保留**：Vosk 预览＋SenseVoice 终稿（`OfflineSpeechInput.kt`、`SenseVoiceSpeech.kt`）、Android 语音（`AndroidSpeechInput.kt`）、`VoiceTranscript.kt`、`SpokenTime.kt`、`VoiceCommandHints.kt`、`LocalAssistantParser.kt`、`NaturalRecordParser.kt`、`RecordNarrationParser.kt`。

**改造**：
- 统一到语音面板状态机（第 3 章 §3.2）；终稿幂等提交（同一 utteranceId 只提交一次）。
- 路由改为“本地指令优先”（第 7 章 §3），修复现状中 `TimeViewModel.fish` 非空时所有输入都发给鱼的问题。
- 本地指令支持范围文档化（第 7 章 §3.2 列表），并有单测覆盖每条语法。

**验收**：飞行模式下“开始计时 学习”“明天下午三点开会”“今天还有什么安排”可执行；鱼运行时正在运行时同样先走本地；迟到终稿不覆盖已编辑文本。
