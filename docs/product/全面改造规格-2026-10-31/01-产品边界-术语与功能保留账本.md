# 1. 产品边界、术语与功能保留账本

> 📌 本章定义产品边界、统一术语和“功能保留账本”。账本是所有改造任务的不退化检查表：任何 PR 修改了账本中的模块，必须在 PR 描述中列出对应编号，并给出验收证据（截图、录屏、测试名或真机记录）。

## 1. 产品定位

时间 Agent 是一个**以时间为主轴的个人管家**：

- **时间管理**：计划（打算做什么）与实际（真的做了什么）分开记录，可对比、可复盘。
- **个人管家**：任务、截止、项目、周期事务、课表、健康、记账、训练、附件、收件箱、个人记忆等日常事务。
- **陪伴**：大肥鱼是唯一的 AI 角色，有人格和共同记忆，可以聊天、语音、主动关心、跨平台（QQ、B 站）活动，并能通过工具操作本地业务。

设计原则（按优先级）：

1. **数据可信**：不丢、不重复写、不偷偷修改；每次写入可追溯、可撤销。
2. **本地优先**：核心业务不需要网络、Key 或运行时。
3. **一致操作**：同类动作在全 App 只有一种交互方式。
4. **陪伴不打扰**：鱼的存在感由用户选择（工具模式/陪伴模式），不改变功能。
5. **诚实**：不确定就提示，失败就说明原因和下一步，不伪装成功。

## 2. 统一术语（UI 文案与代码命名都使用）

| 中文术语 | 代码命名建议 | 定义 | 不要混用的词 |
| --- | --- | --- | --- |
| 日程 | `ScheduleBlock` | 计划中的时间安排。类型：时段、提醒点、全天。可以独立存在，也可关联任务。 | “计划块”“事件”混用 |
| 实际记录 | `ActualRecord`（现存实体名保持） | 真实发生的时间段，可来自计时、补录、专注、训练、健康导入。允许互相重叠。 | “打卡” |
| 任务 | `Task` | 需要完成的事项，有状态与可选截止。完成任务**不会**自动生成实际记录。 | “待办”可作为 UI 同义展示，但同一页面不混用 |
| 截止 | `Deadline` | 任务或事项的到期时间点。 | “DDL”只用于口语提示 |
| 周期规则 | `RecurringRule` | 生成重复实例的规则；实例可手工例外。 | |
| 计时 | `RunningTimer` | 正在进行、尚未结束的实际记录。全局同时最多 1 个“自由计时/专注/训练”主计时（详见第 5 章冲突规则）。 | |
| 专注 | `FocusSession`（拟建） | 番茄钟/专注会话，结束后产生实际记录。 | |
| 鱼 / 大肥鱼 | `Fish` | 唯一的 AI 角色。 | “助手A/助手B” |
| 运行时 | `AgentRuntime` | 内置 Linux（proot）+ Node + DSH。 | “离线模型”（运行时不是离线大模型） |
| 本地指令 | `LocalCommand` | 不经过模型、在本机解析的窄语法命令，例如“开始计时 学习”。它是鱼的“快速通道”，不是第二个助手。 | “离线助手” |
| 共同记忆 | `SharedMemory` | 鱼与用户之间的长期记忆，权威存储在 DSH 侧。 | |
| 个人规则 | `PersonalMemoryRule`（现存） | 用户明确设定的偏好/规则，原生侧存储，供鱼和本地业务读取。 | 与共同记忆混为一谈 |
| 工具模式 / 陪伴模式 | `PresentationMode.TOOL / COMPANION`（拟建） | 视觉呈现模式，不影响功能。 | “简洁版/完整版” |
| 草稿 | `Draft` | 未提交的输入或解析结果，需要用户确认才写入。 | |

## 3. 产品边界

### 在范围内

- 账本中所有现有能力（第 4 节）。
- 第 5 章 10 项新功能。
- 质量规范：大字体、无障碍、深浅色、性能、电量、数据安全、诊断。

### 不在范围内（除非用户另行确认）

- 官方 AI 代理、免费额度、会员、支付、广告。
- 应用商店上架专项工作（备案、公司主体、审核材料）。
- 账号体系与云同步；完整平板/折叠屏专属布局（只保证不崩、可用）；英文界面；全局搜索。
- 离线大模型推理（Linux 运行时只运行 Agent 框架，模型推理仍走用户 Key 对应的云端）。

## 5. 质量底线（所有模块共同适用）

- 所有写操作经统一执行入口（第 6 章），具备幂等 requestId、版本检查、结构化结果。
- 所有删除支持撤销（Snackbar 至少 8 秒）且在历史中可恢复。
- 所有日期时间输入使用统一选择器；所有时间显示遵循用户时区与 24 小时/12 小时偏好。
- 所有页面支持字体放大到 200% 不截断关键操作；触控目标 ≥ 48dp。
- 所有错误：说明发生了什么、数据是否已保存、下一步可做什么。
