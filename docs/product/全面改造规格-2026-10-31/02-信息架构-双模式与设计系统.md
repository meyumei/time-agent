# 2. 信息架构、双模式与设计系统

> 🎨 本章定义导航结构、工具/陪伴双模式、设计 Token、通用组件和文案/无障碍规范。第 3 章的所有页面只能使用本章组件；不得在页面内自造日期输入、确认弹窗或按钮样式。

## 1. 导航结构

### 1.1 底部导航（固定 4 个 Tab + 中央语音动作）

| 位置 | 名称 | 图标语义 | 内容 | 根路由（拟建） |
| --- | --- | --- | --- | --- |
| 1 | 今天 | 太阳/日 | 当前计时、今日概览、三日时间轴、待处理卡片 | `today` |
| 2 | 计划 | 日历 | 日程、任务、截止、项目、周期、课表视图 | `plan` |
| 中 | 语音（动作） | 麦克风 | 点按打开语音面板；长按直接按住说话 | 非路由，`VoiceSheet` |
| 3 | 复盘 | 图表 | 日/周/月复盘、习惯统计、报表、历史问答 | `review` |
| 4 | 管家 | 鱼/管家 | 鱼、生活模块（训练/记账/健康/课表/附件/收件箱/工具）、设置 | `butler` |

规则：
- 每个 Tab 有独立返回栈（Navigation Compose 多返回栈，`saveState=true / restoreState=true`）。切换 Tab 保留滚动位置、筛选、展开状态、未提交草稿。
- 再次点击当前 Tab：若不在根页，回到根页；已在根页则滚动到顶部/今天。
- 语音面板关闭后回到打开前的页面与状态，不切 Tab。
- 系统返回键：先关闭面板/弹层 → 再退出编辑（有未保存修改时询问“保留草稿/丢弃/继续编辑”）→ 再退栈 → Tab 根页时回到“今天” → “今天”根页时退出 App。
- 深层链接（通知、小组件、快捷方式）进入目标页后，返回键回到对应 Tab 根，而不是直接退出。

### 1.2 设置入口

“管家”根页顶部固定“设置”入口；设置一级分组（最多两层，不得藏到第四层）：

1. 外观：模式（工具/陪伴）、深浅色（跟随系统/浅/深）、动态取色、字体大小提示、时间轴默认天数与密度、一周起始日、24 小时制。
2. 提醒与通知：默认提醒提前量、稍后提醒选项、常驻计时通知、免打扰时段、权限状态与修复。
3. AI 与鱼：API Key（BYOK）、模型、运行时状态、主动关心、平台、声音、悬浮窗。
4. 日历同步（N04）。
5. 数据：备份/恢复、导出（N05）、示例数据、诊断包。
6. 关于：版本、开源许可、隐私说明。

### 1.3 现有子 Activity 的处理

`LedgerActivity`、`WorkoutActivity` 等现有子 Activity：第一阶段保留 Activity，但统一主题与顶栏（复用同一 `TimeAgentTheme` 和 `AppTopBar`），并在 Manifest 中设置父 Activity 以保证返回逻辑；第二阶段（T4.x）迁移为同一导航图中的目的地。迁移前后都必须通过账本 L10、L11 验收。

## 2. 工具模式 ⇄ 陪伴模式

### 2.1 共同点（硬约束）

- 同一套 Screen、同一路由、同一布局网格、同一组件；**不得复制页面**。模式只通过 `LocalPresentation`（CompositionLocal，拟建）读取差异参数。
- 切换即时生效，不重建 Activity、不重启鱼运行时、不清空草稿/计时/聊天输入/滚动位置。
- 深浅色是独立维度：可组合出 4 种外观。

### 2.2 差异参数表

| 参数 | 工具模式 | 陪伴模式 |
| --- | --- | --- |
| 鱼在顶栏 | 小圆形头像（24dp），仅状态点 | 角色小像（40dp），有待机动画 |
| 今天页问候区 | 一行文字：日期＋简报摘要 | 鱼的气泡问候＋简报摘要（同样信息） |
| 空状态插图 | 线性图标 | 鱼的插画 |
| 操作反馈 | Snackbar | Snackbar ＋ 鱼的短表情（≤1.2 秒，可在设置关闭） |
| 动效时长 | 标准（150–250ms） | 标准＋角色动画；遵循系统“移除动画”时全部关闭 |
| 主题色 | 中性（蓝灰主色） | 暖色（鱼的品牌色，T2 中从现有 `FishCharacter` 资源取色） |
| 语音面板 | 波形＋转写 | 鱼聆听动画＋转写 |

- 悬浮窗、角色外观、朗读声音是**独立偏好**，不随模式自动开关。
- 新安装时在新手引导（N01）中选择模式，之后可在设置和“管家”页顶部快捷切换。

## 3. 设计 Token

### 3.1 字号（sp，随系统字体缩放）

| Token | 大小/行高 | 用途 |
| --- | --- | --- |
| `display` | 28/36 | 复盘大数字 |
| `title` | 20/28 | 页面标题 |
| `subtitle` | 18/26 | 区块标题、卡片标题 |
| `body` | 16/24 | 正文、列表主文本（默认） |
| `bodySecondary` | 14/20 | 次要说明、列表副文本 |
| `caption` | 12/16 | 仅用于时间刻度、图表坐标等纯辅助信息；不得承载可点击操作或关键信息 |

### 3.2 间距与尺寸

- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32dp。页面左右边距 16dp；卡片内边距 16dp；列表项最小高度 56dp（两行 72dp）。
- 触控目标：所有可点击元素 ≥ 48×48dp。删除现有代码中关闭最小触控的写法（`ui/Timeline.kt` 第 314 行附近 `LocalMinimumInteractiveComponentSize provides 0.dp`）。
- 圆角：小 8dp（标签/输入）、中 12dp（卡片）、大 20dp（底部面板顶部）。

### 3.3 颜色

- 基于 Material 3 `ColorScheme`；支持 Android 12+ 动态取色（默认关闭，设置中可开），关闭时使用模式主题色。
- **语义色稳定，不随动态取色变化**：
  - 计划：描边/浅填充；实际：实心填充；冲突：警示色＋斜线纹理；运行中：主色＋脉冲边框；完成：降低饱和度＋勾选图标。
  - 语义不能只靠颜色：计划/实际同时用填充样式区分，冲突有图标，状态有文字。
- 对比度：正文与背景 ≥ 4.5:1；大字（≥18sp）与图标 ≥ 3:1。T2 中写自动化测试遍历 4 种外观的 Token 对比度。
- 现有 `TimelinePalette*.kt` 的用户自定义颜色保留，但渲染文字颜色由背景亮度自动选择黑/白，以保证对比度。

### 3.4 动效

- 页面切换：淡入＋轻微位移 200ms；面板：从底部滑出 250ms。
- 时间轴拖拽：跟手，无延迟动画；松手吸附 120ms。
- 遵循 `Settings.Global.ANIMATOR_DURATION_SCALE == 0` 时禁用非必要动效。

## 4. 通用组件（拟建 `ui/components/`）

| 组件 | 职责 | 关键行为 |
| --- | --- | --- |
| `AppTopBar` | 页面标题、返回、右侧最多 2 个图标＋溢出菜单 | 标题过长省略；图标必须有 contentDescription |
| `PrimaryFab` | 各 Tab 的“新建” | 今天：新建菜单（日程/任务/实际记录/开始计时）；计划：按当前子页新建 |
| `DateField` / `TimeField` / `DateTimeRangeField` | 统一日期时间选择 | 点击打开 Material3 DatePicker/TimePicker；支持键盘输入模式；Range 组件显示时长；结束早于开始时显示错误并提供“跨到次日”显式开关（不偷偷加一天） |
| `DurationField` | 时长输入 | 快捷 15/30/45/60/90 分钟芯片＋自定义 |
| `RecurrenceField` | 重复规则 | 不重复/每天/工作日/每周几/每月/自定义；生成可读摘要“每周一、三 09:00” |
| `ReminderField` | 提醒 | 多个提醒；提前量芯片；显示通知权限状态 |
| `EntityPicker` | 选任务/项目/标签 | 搜索＋最近使用＋新建 |
| `ConfirmSheet` | 破坏性操作确认 | 只用于不可撤销操作；可撤销的操作不确认，直接执行＋Snackbar 撤销 |
| `UndoSnackbar` | 撤销 | 8 秒；同屏只显示一个，新动作覆盖旧动作但旧动作仍可在历史中撤销 |
| `InlineError` | 字段级错误 | 字段下方红字，焦点移到首个错误字段 |
| `StatusBanner` | 页面级状态 | 权限缺失、运行时离线、同步失败；有操作按钮 |
| `EmptyState` | 空状态 | 说明＋一个主要动作（例如“添加第一个日程”） |
| `LoadingSkeleton` | 加载 | 超过 300ms 才显示，避免闪烁 |
| `DetailSheet` | 条目详情 | 底部面板，半屏/全屏；主操作 ≤ 2 个按钮，其余进溢出菜单 |
| `SegmentedSwitch` | 1/3/7 日、日/周/月 | 单选分段按钮，48dp 高 |

### 4.1 反馈规则

| 场景 | 反馈方式 |
| --- | --- |
| 普通保存成功 | 关闭编辑器即为反馈；不弹成功对话框；必要时 Snackbar（如“已保存，提醒在 08:50”） |
| 可撤销的删除/移动/批量修改 | 立即执行 ＋ `UndoSnackbar` |
| 不可撤销（清空数据、恢复备份覆盖、断开同步并删除映射） | `ConfirmSheet`，写明影响范围 |
| 字段校验失败 | `InlineError`，不弹窗 |
| 冲突（时间重叠） | 允许保存；保存前编辑器内显示“与 X 重叠”提示，不阻塞 |
| 版本冲突（他处已修改） | 弹层展示“你的修改 / 当前版本”，选择“保留我的/使用当前/合并字段”；绝不静默覆盖 |
| 后台失败（同步、导出、鱼工具） | `StatusBanner` 或通知，给“重试/查看详情” |

现有大量 `AlertDialog` 错误提示按上表替换（T2.4）。

## 5. 文案规范

- 全部用户可见字符串迁移到 `res/values/strings.xml`（当前无此文件，大量硬编码中文）。只做中文；结构为将来多语言留余地，但不实现英文。
- 用具体动词：“开始计时”“保存”“稍后提醒”，不用“确定/OK”。
- 时间表达统一：今天 14:00–15:30（1 小时 30 分）；跨天：“今天 23:00 – 明天 01:00”。
- 错误文案模板：`[发生了什么]。[数据状态]。[下一步]`，例如“没能连接到模型服务。你的输入已保留。检查网络或 API Key 后重试。”
- 鱼的台词只出现在陪伴模式的角色气泡和鱼聊天里；系统级文案（错误、权限、确认）保持中性，不用角色口吻。

## 6. 无障碍与大字体（质量规范，非可选）

- 系统字体 200% 下：所有页面无截断关键操作；时间轴块内文字可省略，但详情可达。
- TalkBack：所有图标按钮有描述；时间轴块读作“计划，日程标题，14:00 到 15:30，与 1 项重叠”；拖拽提供等价操作（详情中“调整时间”和“前移/后移 15 分钟”自定义动作）。
- 7 日视图提供“列表模式”作为等价无障碍视图。
- 颜色不是唯一信息载体（见 3.3）。
- 焦点顺序与视觉顺序一致；面板打开时焦点进入面板，关闭后返回触发元素。
