# 第四轮：语音可用性与顶部实时文字

依据用户 2026-10-20 至 21 日反馈记录；修复版本为 0.3.1。用户确认手机为小米／澎湃 OS，具体版本未提供；交付直接提供 APK，不制作 HTML 展示。

## 已确认的问题

- 系统识别返回麦克风权限错误后，底部按钮仍显示“松开识别”。应用授权与系统语音服务授权被混为一谈，用户无恢复入口。
- “取消示例课程”没有对应的本地或云端执行动作，模型只能追问。
- 语音输入需要在首页屏幕上方实时显示文字，松开后仍能核对和修改。

## 本轮实现与验收标准

1. 默认使用 APK 内置的离线中文模型，直接读取前台按住期间的麦克风；无需依赖手机 RecognitionService 或额外填写语音服务 Key。首次准备模型在后台进行，准备和开启麦克风期间分别显示状态。
2. 物理长按与读屏操作都支持开始、结束及取消。系统错误、离开前台和销毁页面取消本次会话，旧结果不得进入新会话；实际录音上限为 60 秒，结束采集后进入识别状态。
3. 独立线程采集、识别线程顺序处理已采集 PCM。音频只在本次内存队列中存在，不落盘、不上传；取消后释放麦克风并丢弃结果。
4. 首页顶部显示实时转写，空内容时显示等待提示。上滑取消清除本次文字。松开后将完整原始转写放在助手上方可编辑输入框。
5. 常见同音误识别可显示有限语法识别得到的可选指令。保留原始转写，用户点击建议后才采用；建议本身不写库，修改仍须单独核对并确认。
6. 本地与 DeepSeek 均支持“取消／删除／清理示例课程”。预览整个内置示例学期中涉及的课程、日期和次数。仅来源为内置 `example-v1`、内置学期且明确标为示例的课程可被纳入；真实导入、同名真实课程、任务与实际记录不纳入。
7. 批量取消在一个事务内重新核对完整清单和版本；存在改动则整体拒绝。取消可从操作历史一次撤销，撤销前也须验证全部条目，避免部分恢复。
8. 权限被拒绝时，提供应用权限入口和重新准备操作；澎湃 OS 用户可检查录音权限及控制中心麦克风开关。

## 验证边界

录音状态、转写显示、取消、确认写入和数据库回退使用受控设备边界与真实 Compose／Room 测试验证；模型归档通过实际资产解包和 SHA256 验证。另用 Windows 中文合成语音通过相同中文模型，验证真实原生识别与中间文字，并如实保留原始误识别及候选结果。

桌面合成语音和 Robolectric 都不能代替用户手机的麦克风实测。构建时检查最终 APK 的模型、各 ABI 原生库、16 KB 对齐与升级签名。实际检查结果见第四轮验收记录。
