# 第三轮 UI 与交互 · v0.3

确认日期：2026-10-20。来源：用户对 0.2.0 的真机截图和本轮反馈。

| 编号 | 要求 | 约定和验收 |
| --- | --- | --- |
| R301 | 首页底部居中的圆形长按语音入口 | 按住录音，松手识别，上滑取消；权限弹窗结束后要求重新按住，不能在松手后偷偷开始。识别结果进入助手预览，修改仍需确认；提供文字入口。 |
| R302 | 在时间轴直接添加事件 | 点击空白定位日期和时间；长按空白后上下拖动选择时段。选择后可新建任务并安排、关联已有任务的计划、或实际记录；表单带入所选时段。保存任务和计划使用同一事务。横滑和平移、双指缩放继续保留。 |
| R303 | 使用 DS 重写 UI | WorkBuddy 指定 DeepSeek v4.1 参与实际 Compose 主题、导航和时间块组件改写；主流程审核并集成。整体采用紧凑工具栏、清楚层级、柔和课程色块和可辨识的深浅主题。 |
| R304 | 改善颜色与冲突可视化 | 不同课程按稳定标识分配颜色；计划以紫色系、实际以绿色系区别。实际记录独立显示，不再把课程和计划挤成窄条；冲突显示标记、重叠时段和可展开清单，而非只在标题前加感叹号。 |
| R305 | 缩放时文字自适应 | 取消固定两三行的显示限制；按块宽高换行、调整字号，并随空间逐步显示时间和地点。极小色块保留完整辅助说明及点击详情，放大后展示更多内容。任何尺寸显示任意长度文字受物理空间限制，不通过无限缩小字号制造“完整可读”的假象。 |
| R306 | 手动切换深浅色 | 首页小按钮选择浅色、深色或跟随系统；选择保存在设备，下次打开保留。四页面和编辑/助手界面使用同一主题。 |

本轮继续保留：默认 00:00–24:00 同屏、连续日期浏览、真实 PDF 导入、五山作息、已有活动模块、助手预览确认及数据保护。数据库仍用 v2，不做删除或破坏性迁移。

可视化预览与自动化能验证布局和手势逻辑；系统语音服务、实际麦克风和各品牌手机手感仍需要真机检验。交付时记录实际测试、APK 签名和这些限制。
