# 第二轮需求与开发计划 · v0.2

需求确认日期：2026-10-20，Asia/Shanghai。来源：用户对 0.1.0 的实际手机测试反馈、两张界面参考图和本学期真实课表 PDF。

本记录是《MVP 产品需求与技术开发规格书 v0.1》的增补；发生冲突时，以本次明确要求为准。参考图用于理解布局，不作为课程数据源。

## 已确认的要求与验收标准

| 编号 | 要求 | 验收标准 |
| --- | --- | --- |
| R201 | 首页以时间轴为主，参考 WakeUp 的紧凑布局 | 去掉独占大块高度的标题、口号、图例及底部“即将开放”条；日期和主要操作集中在紧凑工具栏。 |
| R202 | 默认一屏显示 00:00–24:00 | 根据可用高度计算时间比例；首次打开可同时看到 00:00 和 24:00，无须纵向滚动；放大后允许拖动查看。 |
| R203 | 日期横向连续滑动 | 日期表头与时间块一起连续移动；向左拖动约一天宽度后，由周一至周日变成周二至下周一；允许停留在非整周位置，不使用整周翻页。 |
| R204 | 双指缩放整个时间页面 | 双指捏合改变日期列宽和小时高度，尽量保持手指中心对应时间位置；放大后可平移，提供恢复一屏/本周入口；时间块仍可点击，重叠记录仍可访问。 |
| R205 | 真实 PDF 课表导入可用 | 系统文件选择器读取 PDF；按表格位置识别课程、星期、节次、周次、地点和教师；先预览和修正，再确认入库；以用户本次提供的真实 PDF 验证，不以合成 JSON 代替。 |
| R206 | 同步建设官方教务导入 | 以华工当前官方入口为目标，用户自行在网页登录并进入课表，再提取和预览；复用“学校网页→独立适配→统一模型”的思路。记录入口、解析覆盖和实际验证状态。 |
| R207 | 新建时可选择预设活动，支持父子模块 | 初始提供“睡觉”“健身”，健身下含“练胸、练背、练肩、练手臂”；支持新增和维护活动模板，选择后带入任务名称、分类及建议时长，保存后可计划或计时。 |
| R208 | 开发可使用的第一版语音助手 | 真正接入系统语音识别，同时保留文字输入；本地常用指令直接可用；应用内配置 DeepSeek API Key 后可使用模型理解；所有修改先展示具体预览，确认后执行，失败保留输入。 |

用户已明确接受 R208 的“本地常用指令 + 应用内配置 DeepSeek”方案。密钥不在聊天或代码中提供。

用户随后明确：PDF 中的所有校区课程**统一沿用参考图里的五山作息**，不按课程所在校区分别换算。导入页预填这套作息，保留编辑及确认；2026–2027 第一学期首周周一预填为 2026-08-31，其他学期不猜测日期。

## 与旧版约定的变化

- 原“左/右滑动切整周”改为连续日期浏览，左滑向未来日期；整周箭头作为快捷入口保留。
- 原每小时固定 64 dp、纵向滚动查看全天，改为首次按屏幕高度适配全天，再由双指放大。
- 语音助手从说明占位入口改为真实交互页面；首页不再为占位说明保留整条区域。
- 数据库从 v1 显式迁移，保留已创建的任务、计划、实际记录、课程、历史及计时起点；不允许删除重建。

## 实施安排

1. 保留 0.1.0 安装包和源码基线，检查原有 42 项测试。
2. 实现时间轴几何规则、拖动与缩放，补默认全天可见及多指手势测试。
3. 新增活动模板和关联关系、v1→v2 数据迁移及测试。
4. 真实 PDF 结构分析、Android 端读取、可修正预览、确认导入；官方网页入口和独立解析同步建设。
5. 系统语音识别、本地指令、DeepSeek 客户端与安全配置、修改预览和执行。
6. 集成界面，执行自动化、Lint、APK 构建、签名检查及真实 PDF 验证，输出第二轮验收记录与安装包。

本轮开始时 42 项基线测试对应的 Gradle 验证已通过。每个条目的最终状态以第二轮验收记录为准。

第二轮交付为 0.2.0，实际结果和剩余验证已归档至[第二轮验收记录](../history/第二轮验收记录.md)。本轮按用户授权调用 WorkBuddy 指定 v4.1 模型参与源码修改和复查，所有交付检查由主开发流程独立执行。

## 需要保留的验证边界

- 用户提供的 PDF 仅本地解析；课程内容和姓名不加入公开测试夹具。自动化测试采用同结构的合成数据，真实 PDF 的核对另行记录。
- 未安排星期/节次的实践课程显示为待处理备注，不能伪造上课时间。
- WakeUp 的旧 APK 配置可以帮助定位学校入口，不能据此声称当前官方登录、适配器或 WakeUp 私有接口已可用；真实登录流程需实际测试。
- 语音识别服务取决于手机已安装服务及网络/离线语言支持；文字输入和本地解析应可独立使用。
- 未配置 API Key 时清晰提示；模型请求失败或返回不合法动作时不得写库。首次云端使用应展示发送的数据范围。
- 真实手机上的手势、输入法、麦克风权限、识别服务和教务登录需设备验证；桌面绘制和 Robolectric 不替代这些检查。
