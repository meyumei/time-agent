# 时间轴滑动与今天页顶部修正

日期：2026-11-04。分支：`codex/timeline-scroll-header`，基线：`2c72bbc`（T4.6）。

## 已复现问题与修正

- 三日视图约 12dp 的轻微斜拖就跳整日，横向拖动还会永久改变小时刻度。手势使用系统 touchSlop，识别后锁定单一方向，水平剩余位移至少 48dp 才翻页。1/3 日翻一天，7 日翻一周。
- 原七日视图约 2dp 的无意义溢出会先消耗横移，从而吞掉第一次翻周。仅在实际窄屏时扩展网格宽度，扣除真正内部滚动消耗后，剩余位移参与翻周；日期、全天条目和网格共用滚动位置。
- 单指拖动转双指或取消可遗留半列日期。手势结束统一恢复原整数日期锚点，双指仅作用于纵向。真机新增取消检查先报红；随后仅按“已消费”判断又拦截了正常松手，仍不通过。最终从原生输入观察真正的 ACTION_UP，成功松手提交、合成取消复位，点按和长按选择取消也使用同一事实，保留原用例重新验收。
- 顶部简报收起为单行，日期与日数/过滤/更多合并为一行；1/3/7 日为低调文字下拉。补记时间、本次习惯、处理期限、训练保留在简报旁“＋”菜单，原标签和业务入口保留。简报展开、创建、撤销/重做、冲突、语音、密度、概览、回到今天和主题菜单均保留。
