## 改动

项目内新增任务/子任务使用应用私有偏好保存草稿，包含固定新任务编号、名称、原始分钟文本、父任务选择、原项目快照及版本、打开时可选父任务归属版本、提交请求编号和保存完成标记。

项目列表显示全部任务草稿，项目详情显示本项目草稿；恢复保留原版本，不从最新快照替换。新建与恢复使用相同编辑器，支持共享保留/丢弃/继续编辑选择。原父任务不可用时保留原选择并提示，用户可以明确选择其他层级，不自动解绑。

点击保存冻结当前草稿，校验、内容与请求来自同一份输入，仍经一次 WriteProject(CreateTask) 保存任务及归属。项目/父归属版本变化由已有命令拒绝，保留输入；未修改草稿重复提交和恢复重放使用原请求。保存成功只清当前草稿，清理失败显示已保存且锁定再次写入；沿用八秒撤销。未改变一级子任务、预计耗时或项目归属规则。

影响 L03/L05，关联 L01；没有 schema 或命令模型变更。新偏好的完整备份属于尚未完成的 T6.2，不宣称现有备份已覆盖全部编辑器偏好。
