- 收件箱“转为”菜单覆盖任务、日程、记账、记忆规则和删除。前四项打开现有编辑器并预填原文；取消不写库。确认使用 `ConvertInbox`，新条目与想法归档在同一事务、同一撤销单元中提交，检查所见想法版本并以 requestId 去重。
