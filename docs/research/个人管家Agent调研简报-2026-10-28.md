## 一句话结论

“养鱼就养 DS”不是一个官方产品，而是社区对 **DSH 插件生态里养一只大肥鱼、给它记忆和主动能力** 这套玩法的昵称。真正值得时间 Agent 学的不是桌宠皮肤，而是“真实状态可视化 + 可解释记忆 + 克制的主动唤醒 + 白名单执行”。

## 它为什么有效果

- 大肥鱼用真实 session/task/tool 事件展示思考、工作、等待、完成、错误，不是伪动画。
- 鱼记忆会淡忘但不删除，能解释召回和未召回原因。
- 主动插件有安静时段、每日预算、冷却和静默收尾，“无事可报”不会硬发消息。
- 受限值班模式只给模型少量白名单工具，路径写死，日志可审计。

作者记录过一些单机数据，例如大肥鱼热启动约 1.195 秒、父子进程工作集约 74.2 MB、空闲 CPU 约 0.14%。这些只能算单机 alpha 证据，不能证明 Android 耗电、长期留存或跨设备稳定性。

## 最值得学的四层

1. **人格与状态层**：角色只展示真实流程，不假装在思考。
2. **三层记忆**：稳定画像、带时间的经历、当前工作状态分开。
3. **主动管家**：候选 -> 证据 -> 价值/风险 -> 安静与预算 -> 说话或静默。
4. **执行安全**：模型只能选强类型白名单动作，高风险动作要预览、确认、可撤销。

## 从外部大肥鱼账号迁移的能力

用户真正想要的是大肥鱼已经在 B 站、抖音、小黑盒等平台表现出来的“社交人格”，而不仅是一个视频搜索插件。它应该能发自己的作品、读懂评论上下文、用正常语气回复，并把自己在外部平台遇到的内容和话题带回时间 Agent，像朋友一样和主人继续聊天。

这要求时间 Agent 设计一个共享人格、分开的社交通道：

- **主人私聊**：默认开启，鱼可以分享见闻、表达感受、追问、玩耍和承认不确定。
- **平台浏览**：按用户兴趣发现公开内容，形成鱼自己的见闻。
- **平台公开账号**：逐平台授权后，由鱼在限定人设、主题、工具、预算和安静时段内自主决定是否发作品或回复评论；评论能力默认关闭。

三个通道共享人格风格和经过确认的长期记忆，但不共享登录态、私聊内容和未授权写权限。这里要参考 DSH 插件的“受限值班”方式：主人授权一个边界内的自主通道，不必逐条替鱼确认；宿主负责能力开关、白名单、预算、冷却、日志和随时停止。视频只是话题来源之一，不能把主人聊天设计成“视频卡片列表”。UI 应优先显示连续自然消息，平台、链接和摘要依据放在可选的来源入口中。

## 大肥鱼形象怎么做

可以学“圆胖鲸鱼、亲和、认真工作时反差明显”的气质，但建议做 **原创鲸尾管家**。

不建议直接复用现有角色帧：

- `dsh-pet` README 明确角色素材是 `CC BY-NC-SA 4.0`，非商业、署名、相同方式共享。
- `ds-local-pet` 明确代码 MIT，角色视觉资产不受 MIT 覆盖。
- `dsh-dafeiyu` 与上游 dsh-pet 的素材许可说明存在冲突，旧 BigFish 帧也明确不属 MIT。

因此不要复制现有帧、服装、比例、配色组合、动作序列或 DeepSeek 商标。

时间 Agent 内的大肥鱼会承担管家的人格和真实工作状态表达；喂养、装扮、收集、成长等养鱼互动单独作为娱乐游戏，不参与任务写入、提醒、统计、记忆或权限判断。具体形象等待用户后续提供参考素材。

## 时间 Agent 现在缺什么

当前 `0.11.0 / code17`、Room `v11` 已有不错的底子：

- 强类型 JSON action；
- 本地执行和撤销；
- 简报、建议、个人记忆、提醒；
- 精确闹钟降级和开机恢复；
- 显式数据库迁移与备份表清单。

主要缺口是：

- 人格配置没有独立层；
- 没有统一管家状态总线；
- 记忆没有证据、置信度、事实键、衰减和召回审计；
- 主动建议仍是三类规则加前台 60 秒刷新；
- 没有安静时段、每日预算、静默收尾；
- 没有原创管家形象；
- 没有采纳率、打扰率、回滚失败率等产品指标。

## 推荐架构

```text
语音/文字
  -> 人格与边界
  -> 管家事件总线
  -> 三层记忆
  -> 主动候选与决策
  -> 白名单执行
  -> 简报/建议/管家状态
```

建议按顺序做：

1. 管家内核、人格配置、状态总线，不主动打扰。
2. 三层记忆、事实键、召回审计、Room `v12`、备份恢复。
3. 主动候选、安静时段、预算、静默收尾，复用 `AlarmManager` / `WorkManager`。
4. 原创胖鲸鱼管家形象与应用内状态动画。
5. 可选心情表达、离线反思、云端意图判断。

## 风险与边界

- DSH 是 developer preview，未经过安全审计，不能直接搬进生产。
- 上游测试数字多数是作者声明，本轮没有逐个重跑。
- 目前没有公开的长期效果数据证明主动建议、记忆或宠物能提升完成率。
- 桌面小组件、AppWidget、Glance 仍不在范围。
- 新增记忆/主动表必须同步 Room 迁移、备份恢复和撤销。
- 健康原始数据、私密聊天、密钥不进入云端记忆。
