# T4.1 项目编辑器持久草稿

2026-11-05。测试、lint分析和手机操作仍暂停。

## 改动

项目新建/编辑原来只有 rememberSaveable 字段，没有磁盘草稿和恢复入口。本批新增应用私有偏好草稿，保存固定项目编号、原项目快照与版本、原始截止日期文本、当前名称/截止/状态、提交请求编号和保存完成标记。

每次字段修改立即写入小型本地草稿，项目列表和详情都有明确恢复入口。新建与编辑共用同一个草稿编辑入口，恢复不从当前数据库刷新原版本；后来的更新或删除仍由 CommandExecutor 拒绝，不静默覆盖。

关闭使用保留草稿/丢弃/继续编辑。保存失败保留输入并在弹窗内显示原因；保存成功后只清理该草稿，清理失败时显示已保存并允许再次清理。提交前读取一份当前草稿快照，校验、业务内容和请求编号来自同一份输入。成功结果接共享八秒撤销，业务仍经 WriteProject。

影响 L05，关联 L01。没有 schema、迁移、Key、运行时或鱼变更。本批只覆盖项目本身，项目内新增任务、周目标、截止和周期等编辑器不因此冒称已有持久草稿。

## 源码与编译

核对新建、卡片编辑、列表恢复、页面重建、全字段修改、原版本与固定编号、关闭选择、失败留存、提交快照和成功后清理路径。

实际命令：

```powershell
./scripts/build.ps1 -Tasks @(':app:compileDebugKotlin')
```

初版退出0，73.98秒；补提交快照后的最终编译退出0，10.81秒。证据为 `ledger-evidence/development-20261105/project-editor-drafts.json` 和 `project-editor-drafts-final.json`。既有 aapt2 路径提示和弃用警告保留，编译不等于功能验收。

## 暂停的验收

- 新建及编辑名称、截止、状态；离开页面/切换模式/进程重启后，从恢复入口取回输入。
- 原项目被其他入口修改或删除后恢复，版本冲突不覆盖、不生成另一个项目。
- 保留、丢弃、继续编辑；多个项目草稿互不影响，取消不写业务库。
- 连续点保存和提交中断后重放；保存成功但清理失败的提示与重试，不重复创建。
- 保存后的八秒撤销、历史恢复、时区/截止日边界、200%字体与TalkBack。

以上均未执行。同步小型偏好写入的真实交互与性能未验收；其余计划子页草稿与阶段2–5全项源码对照继续处理。
