# T5.7 报表与导出

2026-11-04。开发记录，未作验收通过声明。

复盘提供本地周报/月报：计划/实际/覆盖/完成率、专注/睡眠、项目/标签、偏差前五、截止、习惯、周目标、训练和记账。板块可选；鱼点评通过同一会话生成并独立显示，不替代本地数字。

支持一张完整长图与分页PDF。长图按条带流式编码单张PNG，不将报表截成固定高度图片，也不需要整张长图位图驻留内存。使用原FileProvider分享。

SAF选择位置，WorkManager后台生成CSV zip、带schemaVersion的JSON及日程ICS；可选时间和数据类型。记录、专注、习惯、训练、提醒、模板与归属数据按相应选择导出，排除示例、Key、凭据和支付通知原文。记账CSV沿用既有字段。

超过2秒显示进度，可取消并清理临时和目标文件；若文件提供方拒绝清理，保留明确提示及通知，页面会实时显示清理失败。可选周一/月初9点报告通知，重启/改时区后重排，通知打开相应日期报告。

影响L01/L02/L05/L09/L10/L11/L18/L20。无新表。恢复验收时打开三个导出格式、完整长图/PDF、取消与提供方拒删、大范围导出、报告通知和鱼不可用。
